# ADR 00065: youtuber.csv の重大刑事事件による個別除外基準

## Context

`youtuber.csv` は、Wikidata の職業と日本語 Wikipedia 記事の存在を基準に、
国内外の YouTuber・VTuber を広く収録する。一方、このファイルは一般向けアプリの
サンプル単語リストとしてランダムに提示されるため、重大な刑事事件で有罪判決を
受けた実在人物を題材に残すことが利用文脈に合わない場合がある。

人物に関する疑惑や刑事手続は変化しうる。逮捕・起訴だけで有罪と扱ったり、
「不祥事」「炎上」の印象で除外したりすると、推定無罪を損ない、国や時代によって
異なる法制度を無批判に取り込む。このため、機械的な犯罪歴フィルタではなく、
客観的な下限と個別レビューの手順を定める。

## Decision

この基準は `category=youtuber` の実在人物の活動名を対象とする。VTuberの
キャラクター名と、その運営者・演者に関する情報を同一人物として扱わない。

重大刑事事件による除外は、次の二つを両方満たす場合に限る。

1. **有罪判決で自由刑が言い渡されている。** 実刑に加え、刑の執行猶予・保護観察を
   伴う自由刑を含む。判決が確定していない場合は上訴状況を確認し、後日の見直し
   対象とする。逮捕・捜査・書類送検・起訴だけではこの条件を満たさない。
2. **一般向け題材として残さないことを個別レビューで決定する。** 犯行の重大性、
   被害、反復性、実際の身柄拘束、動画配信など本人の公的活動との関係を総合する。
   自由刑の言渡しは必要条件だが、それだけで全人物を自動除外しない。

### 確認資料

- 裁判所・検察・警察などが公開する一次資料、または事実確認体制のある主要報道を
  使う。Wikipedia、本人や関係者のSNS、まとめサイト、匿名投稿だけでは決定しない
- 同名人物との取り違えを避け、`original`、活動名、QIDなど複数の識別情報を照合する
- 判決日、刑の種類、確定・上訴状況を確認する。情報が競合する場合は除外を保留する
- 海外事件は、現地制度での処分名を日本の刑事手続に安易に読み替えない

### 除外しない境界事例

次の事実だけでは除外しない。

- 逮捕、捜査、家宅捜索、書類送検、起訴、公判中、保釈・勾留
- 被害申告、報道上の疑惑、民事判決・和解、謝罪
- プラットフォームからの停止・収益化解除、所属先との契約解除、活動休止・引退
- 違法性を伴わない炎上、規約違反、不適切発言
- 罰金・科料・行政処分だけの事案

政治的言論、報道、宗教、政府批判など表現行為を理由とする処罰は、自由刑であっても
自動除外しない。行為の内容、具体的な被害、裁判の公正性、人権上の懸念を別途確認する。
無罪、逆転無罪、公訴棄却、嫌疑なし、誤認が確認できた場合は除外根拠にしない。

日本での知名度はこの基準に混ぜない。国内向けの表示対象は ADR 00064 の `scope` で
選択し、海外中心の人物であることだけを理由にリストから削除しない。

### 運用

- 判断は人による個別PRで行い、犯罪歴データベースやWikidataの属性から自動削除しない
- 対象者の全行を `youtuber.csv` から削除し、正規化済み記事名を
  `tools/update_youtuber.py` の `EXCLUDED` に追加して自動更新での再追加を防ぐ
- チャンネル監査台帳など、CSVの収録者だけを対象とする付随メタデータも削除する
- IDは再採番しない。同じ人物が別の単語リストに正当な収録理由を持つ場合、その行は
  このADRだけを根拠に削除しない
- 生成済みの未参照カードは通常の `gen_youtuber_cards.py --prune` に削除を任せる
- 判決の取消し、再審、人物同定の誤り、基準変更が判明した場合は、個別PRで
  `EXCLUDED` を外し、公開情報を再確認したうえで収録を復元する

## Consequences

- 単なる疑惑や逮捕と、裁判で自由刑が言い渡された重大事件を分離できる
- 一般向けリストとしての適合性を保ちつつ、推定無罪と国ごとの法制度差に配慮できる
- 初回レビューでは9人を個別除外し、逮捕・起訴中、古い事件、政治的処罰、炎上、
  契約解除などの境界事例は収録を維持した
- 完全自動化はせず、追加・復元のたびに根拠確認と編集判断が必要になる
- 個別レビューには価値判断が残るため、将来の判断はこのADRの必要条件・境界事例・
  確認資料をPRごとに一貫して適用する
