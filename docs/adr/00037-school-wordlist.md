# ADR 00037: school(学校名)ワードリストの新規作成と自動更新

- Status: accepted
- Date: 2026-08-02
- Supersedes: none
- Superseded by: none
- Related: 00001(自動更新に使う出典の選定基準) / 00004(stations の差分更新と city 列の粒度) / 00014(既存行を劣化させない) / 00022(gimukyoiku。学校生活の語をカバーする姉妹リスト) / 00036(municipality。市区町村名の出典と総務省コード表の読み方)

## Context

空耳の材料として学校名(「浦高」「札南」「灘校」「北大」…)は日常会話での言及頻度が高く、地名・人名とは別の語彙の層を作る。既存リストには学校名が1件も入っていない。

学校名は全国で6万件規模あり、Wikipedia/Wikidata だけを出典にすると記事のある著名校(高校・大学中心)に偏る。一方で**文部科学省が「学校コード」一覧として全学校の正式名称・所在地・設置区分を機械可読なCSVで公開しており**、これが名簿としては唯一の網羅的な出典になる(政府標準利用規約2.0、CC BY 互換)。さらに Wikidata には **P11127(文部科学省学校コード)** があり、学校コードで名簿と直接JOINできるため、読み仮名(P1814)・別名(altLabel)・QID・ja記事名を名寄せの当て推量なしに結び付けられる。

学校名には他のリストに無い固有の事情がある。

1. **正式名称が長く、そのままでは空耳の表層にならない**。「北海道札幌南高等学校」「札幌市立山鼻小学校」と発話する人はおらず、実際に使われるのは「札幌南高校」「山鼻小」「札南」である
2. **設置者接頭辞(`北海道` `東京都立` `〇〇県立` `〇〇市立`)が名前の半分近くを占める**。これは学校の固有名ではなく設置者の情報で、`founder`/`prefecture` 列に構造化して持てる
3. **口語的な通称(札南・浦高・灘校)は機械生成できない**。「北海道札幌南高等学校」から「札南」を導く規則は無く、当てずっぽうで作れば実在しない略称が大量に混入する
4. **保育所には全国統一の公式名簿が無い**。保育所は児童福祉施設で学校教育法の学校ではないため学校コードの対象外であり、こども家庭庁の公表資料も自治体ごとの様式で、名称の網羅的な機械可読データが存在しない

## Decision

文部科学省「学校コード」一覧を主データ、Wikidata(P11127 でJOIN)と ja.wikipedia を補助、所在地の市区町村名の照合に総務省「全国地方公共団体コード」を使って、`tools/update_school.py` で `school.csv` を生成する。月次バッチ(`update-wordlists.yml`)に載せる。

### 収録範囲

学校コードの対象である**全校種**を収録する。幼稚園 / 認定こども園(幼保連携型) / 小学校 / 中学校 / 義務教育学校 / 高等学校 / 中等教育学校 / 特別支援学校 / 専修学校 / 各種学校 / 大学 / 短期大学 / 高等専門学校。分校も、正式名称に分校名が入った1校として収録する。廃校(名簿の本分校欄が「9(廃)」または廃止年月日が入っている行)は `status=former` として残す。

**保育所は対象外とする**。保育所は児童福祉法の児童福祉施設であって学校教育法第1条の学校ではなく、学校コードが振られていない。全国の保育所を網羅した機械可読・自由ライセンスの公式名簿が存在せず、自治体サイトを個別に集める方式は ADR 00001 の「認証不要・機械可読・差分追記できる単一の出典」という基準を満たさないため、このリストでは扱わない。**幼保連携型認定こども園は学校コードの対象なので収録する**(名称に「保育園」「保育所」を含む園が多数入るのはこのため)。

### 表層は3種類だけにする

1校を1つの `id` にまとめ、`surface` は次の3種類だけを作る。正式名称は全行の `original` 列に入るので、「北海道札幌南高等学校」のような長い行は `surface` には作らない。

| type | 内容 | 例 |
|---|---|---|
| `common` | 設置者接頭辞を落とし、校種語を短縮した通用形 | 札幌南高校 / 日比谷高校 / 山鼻小 / 北海道大学 |
| `name` | 固有部分のみ(接頭辞・校種語をどちらも落とす) | 札幌南 / 日比谷 / 山鼻 / 北海道 |
| `nick` | 口語的な通称・略称。**出典から取れたものだけ** | 札南 / 浦高 / 灘校 / 北大 |

- 校種語の短縮は定型置換だけで行う: 高等学校→高校、中学校→中、小学校→小、小中学校→小中、中等教育学校→中等、高等専門学校→高専、短期大学→短大。該当が無ければ短縮しない(幼稚園・専門学校など)
- 設置者接頭辞は「`立` の直前が行政単位を表す字であること」を要求して落とす(`〇〇県立` `〇〇市立` `〇〇町外二ヶ村組合立`)。この条件を付けないと「国立音楽大学」「東京立正中学校」を壊す。北海道・宮城県・長野県のように `立` を付けずに `北海道札幌南高等学校` `宮城県名取高等学校` と名乗る県立校があるので、上の規則で落とせなかった公立校が自分の都道府県名で始まる場合は、その都道府県名も接頭辞として落とす(私立の「北海道科学大学高等学校」は公立ではないので落とさない)
- 同一 id 内で `surface` は重複させない。接頭辞の無い校名(大学など)では `common` が正式名称と同じになる
- 固有部分が空になる校名(「高知県立盲学校」など)は `common`/`name` を作らない
- 校種語が前後に重なる園(「幼稚園型認定こども園将軍野幼稚園・保育園」「九戸村立幼稚園ひめほたるこども園」)があるので、接尾側の校種語は変化しなくなるまで(最大3回)落とす。ただし短い校種語(小・中・高校)を当てるのは1回目だけにする(「田中小学校」→「田中」→「田」と削ってしまうため)。設置者としての法人名(「学校法人智光学園」)も、法人名の切れ目(学園・学院・会など)まで落とす
- `name` が地名そのもの(山鼻・中央・北海道)になる行もそのまま収録する。このリポジトリは広く収録して利用側で絞る方針で、stations や地名と表層が重なっても困らない

### 通称(nick)は生成せず、出典から取る

`nick` は次の2つの出典から取れたものだけを入れる。

1. **ja.wikipedia の記事冒頭**の「通称は『札南(さつなん)』」「略称は北野高」「通称「浦高」(うらこう)」パターン。丸括弧の読みも同時に取れるのでカタカナ化して `pronunciation` に入れる
2. **Wikidata の altLabel(ja)**

どちらも誤爆(校歌の通称・地名の通称・改称前の旧校名)が混ざるので、次の条件で絞る。

- 2〜8文字であること(「大阪府立南寝屋川高等学校」のような旧校名は長さで落ちる)
- **候補の全ての文字が正式名称か記事名に含まれること**。改称前の別名(緑風冠高等学校の旧称「大東高等学校」)はこの条件で落ちる
- 「学校」「大学」「幼稚園」「こども園」「学園」「学院」で終わるものは通称ではなく正式名称の言い換えなので採らない
- 「附属」「本校」「県立」のような一般的すぎる語は採らない
- **固有部分をまるごと含む5文字以上の候補は採らない**。「有田工業高」「鳥栖商業高」「埼玉県児玉高校」「静岡北特別支援」のように、正式名称を縮めただけで口語的な通称ではないものがこの形になる(実測でnickの2.6%)。固有部分自体を縮めた「大垣日大高校」「文化学園大杉並」は残る

記事の引き当ては Wikidata の sitelink(約2.6万件)を第一とし、**sitelink が無い中学・高校・中等・大学・短大・高専・専修だけは正式名称でWikipediaを引く**。「灘高等学校」はWikidata側にsitelinkが無いが、記事名としてはリダイレクトで「灘中学校・高等学校」に届き、そこから通称「灘校(なだこう)」が取れる。合わせて約2.9万記事を引く。幼稚園・小学校・特別支援・各種学校でこれをやると1万件以上の空振りが増えるので、sitelink がある分だけにとどめる。

それでも Wikipedia 記事がある学校は全体の4割強にすぎないため、`nick` は網羅されない(付くのは6%の学校)。これは「取れた分だけ足す」で構わない。

### 読み(pronunciation)

- Wikidata P1814(名称の読み)とひらがなの altLabel は、実測すると**設置者接頭辞を除いた名称の読み**(「大和市立緑野小学校」に対して「みどりのしょうがっこう」)であることが多いので、`common` の読みとして使い、校種語の部分も表層と同じ規則で短縮する(こうとうがっこう→こうこう)
- 接頭辞込みの読み(「こうべしりつもとやまだいにしょうがっこう」)も混ざっているので、読みの先頭が「〜ケンリツ」「〜シリツ」「〜チョウリツ」なら機械的に落とす。都道府県は47件の読みを持っているので確実に落とせる
- `name` の読みは、そこから校種語の読みを落として作る(みどりのしょうがっこう→みどりの)
- 読みが表層に対して不自然に長い/短い行は捨てる(表層1文字あたり3モーラを上限とする)。表層の校種語と読みの終わりが食い違う行も捨てる(「京都大学」に P1814 の「きょうだい」が付くのを止める)
- カタカナ以外が残る読みは入れない。取れなければ空にする(利用側が表層から推定する)

### 所在地(prefecture / city)は総務省の名簿に照合して切り出す

学校コード一覧の所在地は「北海道札幌市中央区南18条西6丁目1-1」のような住所文字列なので、都道府県名と市区町村名を切り出して持つ。

**住所を正規表現で切ってはいけない**。「市区町村で終わる最長の文字列」を取る方式では、`洋野町種市`(→洋野町) `富岡市七日市`(→富岡市) `香美町香住区`(→香美町) `大阪市城東区古市`(→大阪市) のように大字・地域自治区まで飲み込んだり、逆に `余市`(→余市町) のように切りすぎたりする(実測で2.1%の行が実在しない自治体名になった)。

そこで**総務省「全国地方公共団体コード」現行コード表の市区町村名をホワイトリスト**にし、都道府県名を除いた住所の先頭に前方一致する**実在する自治体名のうち最長のもの**を採る。コード表の1枚目には政令指定都市の行政区が載っていない(2枚目にしかない)ので、この方式なら「札幌市中央区…」は自動的に `札幌市` に丸まり、1枚目に載っている東京23区は `千代田区` のまま残る。stations.csv の city 列と同じ粒度になる。郡・支庁が先に来る住所はそれを落とした形でも照合し、「東京都三宅島三宅村」のように島名が先に来る住所は先頭14字の中から探す。`駒ヶ根市`/`駒ケ根市`、`梼原町`/`檮原町` の表記ゆれは照合時に吸収する。

総務省のExcelは openpyxl を足さずに zipfile + xml.etree で読む。**セルにふりがな(rPh)が埋まっていて、素朴に全ての `t` 要素を連結すると「熊本市西区クマモトシニシク」になる**ので、rPh の下の `t` は読まない。

### 互換漢字は prefecture / city だけ正規化する

文科省の住所には CJK互換漢字が混ざっていて、同じ市が2つの表記に割れる(`宇都宮市` 461行 vs U+FA10系の `宇都宮市` 3行、`宝塚市` 149行 vs 17行)。`prefecture`/`city` は絞り込みに使う列なので、**CJK互換漢字ブロック(U+F900–U+FAFF, U+2F800–U+2FA1F)の文字だけを NFKC で正規化**して統合する。全体に NFKC をかけると `ＥＣＣコンピュータ専門学校` が半角化されてしまうので対象を限る。`original`/`surface` は正式名称なので**変換せず原文のまま**残す(111行に互換漢字が残る)。

### id は学校コードで固定する

`id` は学校コード(`code` 列)に対して固定し、既存 `school.csv` にある学校コードの `id` は再生成しても変えない。新規の学校だけ末尾に追記する(ADR 00014)。名簿から消えた学校コードの行は削除せずそのまま残す。

### 実写を優先し、無い学校は校種別イメージで補う

学校コードで結び付いた Wikidata QID に P18(画像)がある学校は、Wikimedia Commons の画像を `image`、ライセンス・作者の確認先を `image_page` に入れる。同名校を名称だけで自動照合しない。P18が無い学校は、ロゴ・校章・実在校の意匠を使わない13校種の共有SVGで補い、画像内に「イメージ」と明記する。校種別イメージは `tools/gen_school_type_images.py` で生成し、`tools/apply_school_type_images.py` で割り当てる。後から実写が見つかれば校種別イメージを上書きする。

Wikipedia記事に限らず、Wikidata P373が明示するCommonsカテゴリも探索する。ただしカテゴリ内には校章・人物・行事写真なども含まれるため自動採用せず、`tools/collect_school_image_candidates.py` で再利用可能ライセンス、画像寸法、ファイル名による一次フィルタを通した候補台帳を作り、所在地と被写体を確認してから採用する。一般の学校公式サイト画像は、屋外の建築物であっても撮影者の写真著作権が残るので、明示的に再配布可能なものだけを使う。

## Consequences

- 全校種・廃校込みで **60,211校・121,768行・15.8MB** のリストになる(内訳は小学校19,776 / 中学校10,317 / 幼稚園9,748 / 認定こども園8,073 / 高等学校5,119 / 専修学校3,268 / 特別支援学校1,186 / 各種学校1,146 / 大学832 / 短期大学328 / 義務教育学校297 / 中等教育学校63 / 高等専門学校58。廃校4,687)。既存の最大リスト(baseball 28,606行)の4倍の行数・リポジトリ全体を倍にするサイズで、CSVとしては扱えるがクローンは重くなる
- `city` は121,768行中121,766行(99.998%)が総務省コード表に実在する市区町村名になる。空になるのは住所に市区町村が書かれていない1校だけ
- nick の精度は無作為50件の目視で44件が出典どおりの通称・略称(88%)。残りのうち4件は正式名称を縮めただけの異表記で、上のガードで機械的に落とした(落ちた117行を確認したところ全て同じクラスだった)。残る誤りは「統合前の旧校の通称」「高校の通称が附属中の行に付く」の2件で、記事本文の文脈を読まないと判別できないため許容する
- 学校コードで Wikidata と直接JOINできるので、名寄せの誤りが原理的に起きない。同名校(「灘中学校」が兵庫・山口に複数)も取り違えない
- 通称を出典に限定した結果、`nick` が付くのは著名校に偏る。網羅性より正しさを採った判断で、機械生成の略称(「札南」を作る規則)は将来も入れない
- 読みが付くのは45%の行(nickに限れば51%)。Wikidata P1814 の充足率が2割なので、これ以上は伸びない
- Wikidata P18 から Commons 実写が取れたのは7,075校(11.7%)、15,732行。残る学校は13枚の校種別イメージを共有し、全行の画像欄を埋める
- P18なしでP373がある671 QIDをCommonsカテゴリまで調べると、再利用可能ライセンスの候補が635校、寸法・ファイル名の一次条件まで通る推奨候補が545校あった。`tools/school_image_candidates.jsonl` は採用前のレビュー台帳であり、被写体と所在地の確認なしにCSVへ自動適用しない
- 月次バッチでの実行は Wikipedia の冒頭文取得(約2.9万記事)が支配的で35分前後かかる。**逐次では2時間かかったので3並列で引いている**(このリポジトリの他のupdaterは逐次)。取得結果は `tools/.cache/`(Git管理外)に保存し、ローカルでの再実行は差分だけ引く
- 学校名は個人情報ではないが、廃校・分校を含む名簿であり、在校生・所在地の情報は持たせない(住所は都道府県・市区町村までに丸め、番地は捨てる)
- 保育所を含めないため「保育園」を名乗る施設は認定こども園に移行した園しか入らない。全国的な公式名簿が整備されたら再検討する
