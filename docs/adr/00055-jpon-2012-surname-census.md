# ADR 00055: 2012年電話帳を名字の母集団・順位に使用する

- Status: accepted
- Date: 2026-08-15
- Supersedes: 00038-myoji-wordlist.md
- Superseded by: none

## Context

ADR 00038 は、再配布条件を確認できる電話帳由来ソースが見つからなかったため、
電話帳の世帯数・順位を使わず、SudachiDict を母集団、Wikidata の著名人数を
参考順位とした。その後、「ネットの電話帳 - 住所でポン！」の2012年版について、
次の条件を確認した。

- 2012年版は登録なしで公開されている
- [利用方法・利用規約](https://jpon.xyz/pages/about.php)は、公表のための情報を
  誰でも自由に利用できるとしている
- 同規約は過剰な負荷を禁止している
- [robots.txt](https://jpon.xyz/robots.txt)は通常のHTMLページを禁止していない。
  PDF、XLS、CSV等は禁止対象なので取得しない
- 各町域ページには、個人明細とは別に「この地域に多い苗字」「この地域の希少苗字」
  という苗字別のローカル軒数表がある

2026年8月15日に100町域を同時実行1・原則10秒間隔で取得した結果、掲載7,741件に
対して苗字6,263軒、異なる苗字685種を抽出できた。2種類の苗字表には延べ1,185件の
重複があったが、軒数の矛盾は0件だった。また、同じ町域のページ分割間では苗字表が
同一であり、町域ごとに1ページだけ取得すればよいことを確認した。詳細は
`docs/tasks/jpon-2012-pilot.md` に記録する。

## Decision

名字の母集団、2012年電話帳掲載世帯数、順位は、住所でポン！2012年版の全町域に
掲載されたローカル苗字軒数を自前集計して作る。SudachiDict を母集団にはしない。

- サイトマップにある2012年版URLを町域単位に正規化し、各町域を1回だけ取得する
- 「多い苗字」と「希少苗字」を苗字で和集合する。同じ苗字が両方にある場合は、
  軒数一致を要求して1回だけ数える
- サイトが表示する外部由来の全国順位・全国軒数は使わない。全国軒数と順位は、
  全町域のローカル軒数だけから再計算する
- 生HTML、個人名、電話番号、住所は保存・コミットしない。保存するのはURLごとの
  完了状態と苗字別軒数だけとする
- 同時実行は1、既定の間隔は10秒＋揺らぎとし、403では停止する。429・5xxは
  `Retry-After` と指数バックオフに従う。アクセス規制の回避はしない
- 中間状態はGit管理外の `tools/.cache/` にSQLiteで保存し、中断後に再開できるようにする
- 読みは集計後にSudachiDict、JMnedict等の再配布可能な読みソースを左結合する。
  読みが見つからない電話帳姓は削除せず、読み未確認として残す

これはADR 00001の「HTMLを無人の定期更新ソースにしない」という原則に対する、
一回限りのスナップショット生成の例外である。月次ワークフローには追加しない。

全国取得が終わるまでは `myoji.csv` の母集団や `rank` を変更しない。切り替え前に、
全サイトマップのURL被覆、取得失敗、表間の軒数矛盾、地域別サンプル、出力スキーマ、
READMEの出典・利用条件表示をレビューする。

## Consequences

- 電話帳に掲載されたがSudachiDictにない苗字も母集団に含められる
- `rank` を著名人数ではなく2012年電話帳掲載世帯数に基づく順位へ置き換えられる
- 電話帳非掲載世帯、掲載拒否世帯、携帯電話のみの世帯等は母集団外なので、人口順位・
  国勢調査ではなく「2012年電話帳掲載世帯順位」と明記する必要がある
- HTML構造変更と長期取得に備え、パーサーの構造検査、再開機能、集計監査が必要になる
- 100町域の試行は単一地域に偏っている。全国精度の評価は全件取得後に行う
- 公開する集計値には出典URL、基準年、取得日、集計方法を付記する。元の個人明細は
  再配布しない
