# ADR 00062: Jpon集計による名字リストへの置換

- Status: accepted
- Date: 2026-08-17
- Supersedes: 00038-myoji-wordlist.md / 00054-defer-myoji-attestation-levels.md / 00055-jpon-2012-surname-census.md / 00058-jpon-2000-surname-census.md
- Superseded by: none

## Context

名字リストの母集団と順位を、実際の掲載を反映したデータへ段階的に更新したい。
全国分の収集完了を待たず、取得済み地域が増えるたびに同じ基準で再生成できる必要がある。

## Decision

`myoji.csv` はJpon 2000年版から名字単位に集計した表記を母集団とし、既存の名字辞書に
読みがある行だけを収録する。既存の `myoji.csv` はこの集計結果で置き換え、未観測の
名字は残さない。

`listing_units` は同じ名字と電話番号の掲載を1単位として重複除去した件数とし、電話番号が
ない掲載は行単位で数える。`strict_rows` は氏名の厳格判定を通った元掲載行数、`regions` と
`prefectures` はその名字を観測した町域数と都道府県数とする。

`rank` は `listing_units` の降順による競争順位とする。同数は同順位で、
次の順位は飛ばす。この順位は取得済み地域内の暫定順位であり、全国人口順位・世帯数順位
ではない。収集範囲が増えた更新では全行を再計算する。

同じ名字表記の複数の読みは従来どおり同じ `id` を共有する。Jponの掲載は表記の根拠で
あって読みの根拠ではないため、`verified` と `evidence_sources` は既存の読みの確認結果を
維持する。

公開CSVには名字単位の集計結果だけを含める。個人の氏名、電話番号、住所、それらの
ハッシュ値、および具体的な掲載地域は含めない。

## Consequences

- 収集途中でもsoramimicとsoramimic-videoで同じ名字リストを利用できる。
- 件数と `rank` は収集の進行で変わるため、確定した全国値として表示してはならない。
- Jponで未観測の名字と、既存辞書に読みがない新規候補は公開リストに入らない。
- 公開出典だけを使う従来の月次更新は、このリストを上書きしない。
