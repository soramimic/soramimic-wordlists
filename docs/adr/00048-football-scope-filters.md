# ADR 00048: football の収録範囲をフィルター可能にする

- Status: accepted
- Date: 2026-08-09
- Extends: ADR 00047

## Context

ADR 00047 では `football.csv` をJリーグ在籍経験者へ絞った。一方、メッシや
マラドーナのような世界的に著名な選手と、Jリーグを経ず海外で活動する日本人選手も、
利用者が明示的に選べる形なら同じリストに残す価値がある。

## Decision

- 人物ごとに排他的な `scope` を付ける。値は `jleague`、`world`、
  `overseas_japanese` の3つとする
- 判定が重なる人物は `jleague`、`overseas_japanese`、`world` の順に優先し、
  同じ人物を重複収録しない
- 利用側の既定値は `jleague` だけとする。他の2区分はフィルターで任意に追加する
- `world` はWikidataでサッカー選手、日本語版Wikipedia記事あり、sitelink 80以上を
  候補条件とする。さらに日本語版記事の冒頭が本人をサッカー選手と説明している場合
  だけ採用する。取得時のsitelink数とQIDをmanifestへ記録する
- `overseas_japanese` はWikidataで日本国籍のサッカー選手、日本語版Wikipedia記事
  あり、国外クラブ所属歴ありを候補条件とする。日本国内クラブ所属歴、Jリーグ公式
  照合済みQID、日本以外の競技国がある人物は除外し、不明な場合は採用しない
- 読みはWikipedia記事冒頭から取得し、推測できない人物は `unverified` とする
- Jリーグ経験者のチームはJリーグ公式の最終所属を正式クラブ名で1つ表示する。
  他の区分はWikidataの所属時期から最新または最終所属を1つ表示する

## Consequences

- 既定の利用感とJリーグ公式照合の品質を維持したまま、追加対象を選択できる
- `world` は主観的な手選びではなく再現可能な代理指標になるが、sitelink数には
  言語圏の偏りと経時変化があるため、manifestの記録と候補レビューが必要になる
- Wikidataの所属情報が欠ける海外日本人は誤採用を避けるため収録されない
- 同じ人物は1区分だけに属するため、たとえばJ経験のある著名選手は `jleague` として
  表示され、`world` 単独フィルターには現れない
