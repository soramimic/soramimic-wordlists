# ADR 00060: にじさんじ公式名簿によるVTuber収録補完

- Status: accepted
- Date: 2026-08-17
- Supersedes: none
- Superseded by: none
- Related: 00011(YouTuber/VTuber収録), 00018(画像), 00056(チャンネル由来)

## Context

従来のVTuber収録は、Wikidataで職業が付与され、日本語Wikipediaに個別記事がある
人物に限られていた。この条件では、公式に現在所属していても個別記事のない
ライバーを多数取りこぼす。

にじさんじ公式タレント一覧と個別プロフィールには、現在掲載中のタレントについて
名前、読み、所属、デビュー日、公式YouTubeチャンネル、プロフィール色が揃っている。

## Decision

`tools/update_nijisanji.py` で公式タレント一覧を補完ソースとして同期する。

- 対象は「にじさんじ」と「NIJISANJI EN」。VirtuaRealは別ブランドで、YouTubeを
  主活動先としないため対象外とする
- 新規人物は公式の名前と読みを使い、`full` 1行だけを追加する。既存人物のID、表記、
  読み、説明は上書きしない
- 公式プロフィールが明示するYouTubeチャンネルIDを由来台帳へ保存し、登録者数更新で
  利用する
- 公式プロフィール色を本人別の象徴カードに使う。公式立ち絵の利用判断と適用は
  [00063](00063-nijisanji-profile-images.md) に分離する
- 対象人数、名前・slugの重複、読み、チャンネルID、デビュー年、色を検証し、公式側の
  構造変更や欠損時は更新を中断する

## Consequences

- 日本語Wikipediaの個別記事の有無に左右されず、公式に現在掲載されているライバーを
  継続的に収録できる
- 公式色を使うことで、同じ事務所で似通っていた生成カードを人物ごとに識別しやすくなる
- 公式一覧から外れた人物の自動削除や `former` 化はしない。履歴を残す既存の追記専用方針と、
  `current` から `former` への慎重な一方向更新を維持する
- 公式サイトの構造に依存するため、スキーマ変更時はパーサの追従が必要になる
