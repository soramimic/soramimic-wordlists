# ADR 00041: gimukyoiku の画像なしをSVGと分割生成で解消する

- Status: accepted
- Date: 2026-08-07
- Related: 00027 / 00028 / 00037 / 00039 / 00040

## Context

既存画像の品質改善後も `gimukyoiku.csv` には画像なしが496語残っていた。文法、制度、
化学式、回路、情報処理などは、生成イラストより正確な文字・記号・関係を示す図が
適している。一方、四字熟語、文学・音楽作品、情景を伴う表現は、図表だけでは意味が
伝わりにくい。

先行作業で374語を白背景の作図SVGへ置き換えた後、国語102、音楽19、美術1の計122語が
画像なしとして残った。

## Decision

- 残る122語のうち、文法・評論用語など16語を決定的SVGにする
- 四字熟語、教材作品、合唱曲など106語は場面イメージにする
- 生成はChatGPT Webの利用可能なブラウザセッションを使い、1枚を最大7x7の49セルに
  分割して生成する。上限時は別セッション、両方利用不能なら `gpt-image-2` を使う
- 生成画像は匿名の人物と一般的な物だけを使い、近現代人物の肖像、既存作品・
  キャラクター、ロゴ、商品意匠を描かない
- `tools/gimukyoiku_final_image_plan.json` を122語の分類と生成プロンプトの台帳にする
- SVGは `tools/gen_gimukyoiku_final_figs.py`、CSVとmanifestへの反映は
  `tools/apply_gimukyoiku_final_images.py` で再現できるようにする
- PDFだった「原稿用紙」とWebMだった「越天楽」は、動画でも読める静止SVGへ置き換える
- 画像は従来どおり `gimukyoiku-image-v1` / `-v1b` Releaseで配布する

## QC

- 新規SVGと生成画像を黒背景へ合成し、動画側の可視性判定を全件通す
- 現行Releaseラスター759枚をラベル付きコンタクトシートで全件確認する
- 意図的な複数場面の説明図は維持する
- 「わたしを束ねないで」だけに隣セル「卒業ホームラン」の混入を確認したため、
  元セルを内側へ再トリムして同じRelease URLへ上書きする

## Consequences

- 3665語すべてに静止画像が付き、PDF・動画など画像として読めない形式も残らない
- SVGは再生成可能で、文字や関係を正確に表示できる
- 7x7生成は生成回数を減らせるが、セル境界の混入を防ぐため分割後の全件確認が必要になる
