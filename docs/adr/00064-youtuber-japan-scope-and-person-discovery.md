# ADR 00064: チャンネルを人物発見に使い、日本向け活動圏を分離する

- Status: accepted
- Date: 2026-08-17
- Related: 00011(人物リスト) / 00056〜00058(チャンネル本人確認) / 00060(公式名簿補完)

## Context

従来の母集団は、WikidataでYouTuberまたはVTuberの職業を持ち、日本語Wikipedia
記事がある人物だった。国内外を区別しないため、世界的には著名でも日本語圏では
馴染みが薄い人物が混ざる。一方、国内で広く活動する人物でも、個人のWikidata職業
や日本語Wikipedia記事がなければ収録できない。

チャンネル名やグループ名をそのまま替え歌の語彙にすると、長さや読みの点で使いにくい
ものが多い。しかし公式チャンネルと公式プロフィールは、人物の発見と本人確認には
有用である。

## Decision

1. `youtuber.csv` は引き続き人物・VTuberキャラクターの活動名だけを語彙行にする。
   チャンネル名は `channel` の付加情報に限定し、`original` / `surface` を作らない。
2. 公式プロフィールまたは公式名簿が、人物の活動名・読みとYouTubeでの活動を
   明示する場合は、レビュー済みの `tools/youtuber_japan_people.json` を経て人物を補完
   できる。チャンネル名から人物名を推測したり、検索結果を直接CSVへ入れたりしない。
   個人チャンネルは登録者数更新にも使えるが、グループ共有チャンネルは人物発見・
   本人確認・`channel` 表示だけに用い、その登録者数を個人へ帰属させない。
   共有IDは根拠台帳で`verified_shared_group_channel`として記録する。表示中の
   チャンネルが共有チャンネルだけならCSVを`channel_shared=yes`とし、
   `subscribers`と`subscribers_as_of`は`NA`にする。別の検証済み個人チャンネルを
   持つ人物は、その個人チャンネルを表示・集計し`channel_shared=no`とする。
3. 初回は既存母集団で欠落していた国内クリエイター5人（ヒカル、きまぐれクック、
   カジサック、ポッキー、瀬戸弘司）を公式根拠付きで補完する。
4. `scope` 列を追加し、`japan` / `global` / `unknown` の排他的な値を持たせる。
   利用側の日本向け既定は `japan` とし、`global` と `unknown` は任意に追加できる。
5. `scope` は国内知名度の点数でも国籍列でもない。判定の優先順位は、レビュー済み
   override、公式名簿の国内外区分、明示済みの人物ソース、公式所属の国内外区分、
   Wikidataの国籍である。根拠が足りなければ `unknown` とし、日本語記事や日本語表記
   だけを理由に `japan` にしない。
6. 同じ人物IDの姓名分割行はすべて同じ `scope` を持つ。CIで許可値、空欄、ID内の
   一致を検証する。

## Consequences

- 世界の人物を削除せず、日本向け利用時に海外中心の人物を除外できる。
- 公式チャンネルやグループは、語彙を増やさず人物候補の探索範囲だけを広げられる。
- `unknown` は誤って海外扱いしないための保留区分であり、根拠の追加に伴って減らす。
- チャンネル共有グループの構成員は、公式ページが人物との対応を明示する場合だけ
  個別人物として追加する。
- 公式名簿の補完は、既存人物の表記や読み、個人チャンネルを上書きせず、欠損している
  所属・活動開始年・説明・チャンネル表示だけを補う。
