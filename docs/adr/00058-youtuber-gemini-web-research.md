# ADR 00058: Gemini Web検索をYouTuber候補探索に使う

- Status: accepted
- Date: 2026-08-15
- Related: 00056(channel補完と由来台帳), 00057(本人直結ソースの拡張)

## Context

ADR 00057の適用後も972人中133人はchannelが欠損していた。この中には著名人も含まれ、
本人記事の外部リンク節だけでは、本文中の開設記述、YouTube概要欄の本人名、所属先が
明示した個人チャンネルを拾えなかった。

## Decision

1. 認証済みChrome上のGeminiまたはCodexの標準Web検索で、候補チャンネルURLと人物との
   対応を示す根拠URLを同時に探索する。
2. Geminiの回答や検索順位は採用根拠にしない。本人公式ページ、本人QIDの記事、
   YouTube概要欄など、人物と同じチャンネルを直接結ぶページを再確認する。
3. グループ共有チャンネルは、本人・所属先の公式ページまたは本人記事が構成員と
   チャンネルを直接対応付ける場合に限り採用する。第三者記事だけの対応、根拠URL欠落、
   削除済みは候補レポートへ残し、CSVへ書かない。採用した共有チャンネルは
   `verified_shared_group_channel`として人物確認と表示にのみ使い、グループの登録者数を
   個人へ付けない
4. 採用レコードは`source_type=web_search_primary_link`とし、`discovery_method`に実際の
   探索経路を記録する。根拠種別と短い根拠要約を必須にする。
5. 個人チャンネルのcanonical UC ID、正式名、登録者数はYouTube Data APIで再取得する。
   複数の個人チャンネルは従来どおり、全候補を合流した後に登録者数最大の同一レコードを
   選ぶ。共有IDはこの選定候補へ入れない

## Consequences

- Web検索を安全な候補発見へ利用できる一方、AIの推測や壊れたURLはCSVへ混入しない。
- 採用・保留の双方に探索方法と根拠URLが残り、後から判断を再現できる。
- 972人のchannel網羅率は作業開始時の685人（70.47%）から930人（95.68%）へ向上した。
  補完245人の取得元はWikidata P2397が22人、Wikidata YouTube handleが20人、
  ja.wikipedia外部リンクが50人、同infoboxが56人、Wikidata公式サイトを人手確認した
  ものが6人、Gemini/Codex通常Web検索で一次リンクを再検証したものが91人だった。
- 42人はchannelをNAのまま保持した。うち直接対応を確定できない候補・削除済みなど
  14人分は候補レポートへ残し、候補自体を得られなかった人物へ推測値を書かなかった。
