# ADR 00058: 2000年電話帳を名字の母集団・順位に使用する

- Status: accepted
- Date: 2026-08-15
- Supersedes: 00055-jpon-2012-surname-census.md
- Superseded by: none

## Context

ADR 00055では、登録なしで閲覧できる2012年版の町域別苗字表を全国集計する方針を
採用した。その後、有料版を契約し、2000年版にも同じ「この地域に多い苗字」および
「この地域の希少苗字」と、その町域内の軒数が掲載されていることを確認した。

今回の用途は現在人口の推定ではなく、固定電話帳を母集団とする名字の相対順位である。
携帯電話への移行が進んだ2012年版より、固定電話の利用が広かった2000年版を基準年に
するほうが、電話帳母集団としての世帯被覆を期待できる。ただし、いずれも電話帳への
掲載・非掲載による偏りがあり、国勢調査や全人口の順位ではない。

2000年版は公開サイトマップには収録されないが、認証済み有料版では年度トップから
都道府県、市区町村、町域の順にHTMLリンクを辿れる。`robots.txt`が禁止するPDF、XLS、
CSVは取得せず、通常HTMLに表示された苗字別ローカル軒数だけを使う。個人名、電話番号、
住所、生HTMLは保存しない。

## Decision

名字の母集団、電話帳掲載世帯数、順位の基準年を2012年から2000年へ変更する。

- 認証済みの2000年版年度トップから、都道府県、市区町村、町域のHTMLリンクを次階層
  だけ抽出し、SQLiteキューへ保存する
- 町域ページはページ分割を正規化し、町域ごとに1回だけ取得する
- 「多い苗字」と「希少苗字」のローカル軒数を和集合し、重複する苗字は軒数一致を
  必須として1回だけ数える
- サイトが表示する全国順位・全国軒数は使わず、全町域のローカル軒数から再計算する
- 認証Cookieは起動時に利用者自身のローカルChromeから取得し、プロセスのメモリ内だけで
  使用する。ログ、SQLite、CSV、リポジトリには保存しない
- 同時接続は1とし、各レスポンスを完全に受信・解析・保存してから10秒待つ。403では停止し、
  429・5xxでは`Retry-After`と指数バックオフに従う。アクセス規制を回避しない
- 途中状態と集計結果はGit管理外に置き、2012年版の試験データとは年度別に分離する
- 全国取得完了までは既存の`myoji.csv`を変更しない。完了後に地域被覆、取得失敗、表間矛盾、
  読みの左結合、順位タイを監査してから切り替える

## Consequences

- 固定電話がより広く使われていた時点の電話帳を、名字順位の基準にできる
- 2000年以降に生じた名字・表記変更や当時の掲載拒否世帯は反映されない
- 有料版の有効な利用者セッションが必要であり、認証切れ時は収集を停止して再認証する
- 100町域の試行では2秒待機でエラーがなかったが、119町域保存後の連続運転中に
  HTTP 403となったため、長期運転は10秒待機へ戻す。403後は冷却し、自動再試行しない
- 公開時は「2000年電話帳掲載世帯数・順位」であること、取得日、集計方法、出典を明記する
- 2012年版100町域の試験結果は方式検証として残すが、2000年版の集計値へ混ぜない
