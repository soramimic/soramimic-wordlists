# ADR 00043: 野球・サッカー選手の説明文とポジション

- Status: accepted
- Date: 2026-08-08
- Supersedes: none
- Superseded by: none

## Context

`baseball.csv` と `football.csv` には名前・所属・画像はあるが、選手の経歴や主要な
実績を短く紹介する情報とポジションがない。同じ選手に姓名・登録名など複数の表層行
があるため、付加情報を表層ごとに取得すると内容が不一致になりうる。また歴代選手
には同姓同名の別人やWikipedia記事が存在しない人物も含まれる。

## Decision

- 両CSVに `description` 列を追加する。同じ `id` の全行には同じ値を入れる
- 日本語版Wikipediaの記事冒頭から、`wpnames.make_player_description` で完結文を
  作る。受賞・優勝・記録などの実績文があれば情報量の多い1文を優先し、なければ
  経歴・代表歴・所属などを含む通常の人物説明を収録する
- 動画カード上で約2行に収めるため50文字を目安とする。ただし完結した実績文を
  不自然に切らないよう65文字までは許容し、それを超える文だけ末尾を `…` で
  省略する。生没年・原語表記などの括弧書きは省略前に除去する
- カード単体で意味が通る文にする。「また」「同年」「その後」「この年」「翌年」
  のように前文を必要とする表現、指示対象が不明な「チーム」、「〜するなど。」
  「〜しており。」のような未完の語尾は採用しない。CSV検証と自動更新PRの
  Geminiレビューでも混入を止める
- CSV検証では、同じ選手IDの `original` とフルネーム表記を候補に、
  ミドルネームや空白の差があっても「〜は、」と人名を繰り返す説明を拒否する。
  略称と本名が一致しない場合も、後半が野球・サッカー選手の肩書きなら検出する。
  親族や現役時代、出生地を主語にする文は対象外とする
- 記事冒頭だけでは代表的実績が出ない著名選手や、「同年には」のような文脈依存の
  断片、カード上の氏名と主語が重複する例は、出典で確認できる短い固定要約を使う
- 記事冒頭に野球なら「野球」、サッカーなら「サッカー」または「フットボール」が
  ある場合だけ本人の記事とみなす。同姓同名の別人記事は採用しない。Wikipediaの
  `disambiguation` pagepropと本文の人物一覧パターンを確認し、曖昧さ回避ページも
  採用しない
- 記事がない、または本人と確認できない選手は空欄にする。推測で補わない
- 著名選手は出身地や肩書だけでなく、主要大会、受賞、記録を優先した固定要約を
  使う。footballの既存データに混入していた曖昧さ回避ページ・別人記事・未完文は
  空欄へ戻し、本人の記事を確認できた場合だけ再補完する
- `tools/enrich_player_descriptions.py` は空欄だけを補完し、既存値を上書きしない。
  取得結果を `tools/.cache/player_descriptions.json` に逐次保存して再開可能にする
  (`--refresh` を明示した場合だけ取得済みの説明文を再生成する)
- 月次更新で追加する現役選手には、ロースターから確定した記事の冒頭を使って
  `tools/update_baseball.py` / `tools/update_football.py` が説明文を付与する
- `position` 列を追加する。野球は `投手/捕手/内野手/外野手`、サッカーは
  `GK/DF/MF/FW` に正規化し、複数は `/` 区切りにする
- 現役選手のポジションはWikipediaのロースターテンプレートの区分を優先し、
  歴代選手はWikidataの選手のポジション(P413)から
  `tools/enrich_player_positions.py` で空欄だけ補完する
- 同名人物の曖昧さ回避ページでWikidata項目を特定できない場合は、競技に応じて
  記事名の `（サッカー選手）` / `（野球選手）` 付き候補も確認する。候補方式を
  変更した際は、旧キャッシュの未解決項目だけを一度再取得する
- Wikidataで取得できない著名選手の明白なポジションは、確認済みの固定値で
  補完する（王貞治=`内野手`）

## Consequences

- 利用側は表層の種類に関係なく、選手単位で一貫した短い紹介文とポジションを
  表示できる
- Wikipedia冒頭に書かれていない細かな記録は収録されず、記事のない選手は空欄の
  ままになる
- 上流記事の改稿で既存説明が毎回変わることはなく、更新差分は新規補完中心になる
