# ADR 00055: YouTuberのチャンネル名をYouTube APIの公式タイトルに同期する

- Status: superseded
- Date: 2026-08-15
- Superseded by: 00056 の既存channel保護規則
- Supersedes: 00029 の channel 取得・更新規則
- Related: 00014(既存値の保護) / 00029(channel列) / 00030(登録者数スナップショット)

## Context

`channel` は Wikidata の P2397 に付く P1810 から取得していたが、この修飾子は
P2397 本体より欠損が多い。972人中、登録者数は706人で取れる一方、チャンネル名は
685人に留まり、22人は同定済みのチャンネルIDと登録者数があるのに名前だけ `NA`
だった。また、Wikidataの古い登録者数で選んだ名前とYouTube APIの最新登録者数が
別チャンネルを指す可能性があった。

## Decision

1. 登録者数更新時の `channels.list` に `snippet` を加え、同じチャンネルIDの
   `snippet.title` と `statistics.subscriberCount` を一組で取得する。
2. 複数チャンネルは最新登録者数が最大のIDを選ぶ。同数ならチャンネルIDの昇順で
   決め、APIの返却順や改名で選択が揺れないようにする。
3. `channel`、`subscribers`、`subscribers_as_of` を同じ処理・一時ファイルで
   原子的に更新する。名前または登録者数が取れない人は3列とも `NA` にする。
4. チャンネル名はASCIIカンマと二重引用符を除き、空白を1つに揃える。これは
   クオート非対応の既存CSV利用者との互換性を守るためである。
5. YouTube上の改名を反映するため、channelも毎回更新する。これは確定的な手修正値を
   守るADR 00014の例外だが、YouTube公式の現在名という列の意味を明確にできる。

## Consequences

- P2397がある人について、P1810の有無に依存せずチャンネル名を表示できる。
- 初回同期では、チャンネル名が685/972人から706/972人へ増えた。22人を新規補完し、
  YouTube公式名との差があった91人を同期し、APIで取得不能な削除済み1人を `NA` にした。
- チャンネル名と登録者数は必ず同じチャンネルを指し、取得日も一致する。
- 網羅率の次の上限はWikidataのP2397自体の有無であり、それを超えるには別経路での
  チャンネル同定が必要になる。
