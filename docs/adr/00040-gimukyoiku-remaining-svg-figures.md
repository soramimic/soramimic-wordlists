# ADR 00040: gimukyoiku の残存SD記号画像をプログラム作図へ置き換える

- Status: accepted
- Date: 2026-08-03
- Supersedes: none
- Superseded by: none
- Related: 00028 / 00037 / 00039

## Context

ADR 00039 の場面画像スイープ後、ng 判定のSD画像は69語残った。内訳は国語14語、
音楽21語、数学34語である。いずれも、活用表、詩形、楽譜記号、数式、幾何図など、
正しい文字・線・位置関係そのものが意味を担う。生成イラストでは字形や音符、比、
交点が誤る可能性があり、再生成して選ぶ方式にも向かない。

## Decision

`tools/gen_gimukyoiku_remaining_figs.py` で69語を自己完結SVGとして描く。
ADR 00037 の数学SVGと同じ320x200の作図基盤、色、ファイル名、Release配布方式を使う。

- 国語14語は、活用例、文節区切り、漢詩の字数・句数、修辞の対応を正確な文字で示す
- 音楽21語は、五線、音符、強弱記号、速度・反復記号、音階をプログラムで描く
- 数学34語は、数値例、単位、等分、座標、合同・対称などの関係を計算可能な図で示す
- 生成AIを使わないため「AIイメージ」札は付けず、manifestの`method`は`svg`とする
- 既存の `gk_<sha1>.jpg` と同じキーで拡張子だけ `.svg` にし、CSVのURLを更新する
- 69枚をブラウザ描画した教科別コンタクトシートで全件目視確認する

## Consequences

- ADR 00039でngと判定された145語は、場面画像79語と作図SVG69語（うちweak前倒し3語）
  の作業により処理済みとなる
- 69語は拡大しても劣化せず、文字・音楽記号・数学的関係を教材として読める
- 図の正しさはコードに依存するため、変更時はXML構文検証とブラウザ描画の目視確認を行う
- 利用側リポジトリのwordlists submoduleは、このCSV更新を含むコミットへ追随させる
