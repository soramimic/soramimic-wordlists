# ADR 00028: gimukyoiku の残り行を生成イメージで埋める

- Status: accepted
- Date: 2026-07-30
- Supersedes: none
- Superseded by: none
- Related: 00027(実写収集と対象の線引き) / 00006, 00010(fictional。AI生成画像のRelease配布) / 00002(pokemon。文字と配色だけのカードの前例)

## Context

ADR 00027 で実写・図版(Commons)を 777 行に付与した後、残り 1,090 行が空欄だった。ユーザー方針により、概念語はAI生成イラスト、歴史上の人物は想像画、実写が取れない実在の作家・作品も顔や作品デザインを描かない象徴イメージで「全行に画像を付ける」ことにした(近現代の実在人物の肖像と保護期間内の作品の複製は生成しない。00027 の線引きどおり)。

生成には fictional-scientists で実績のあるローカル SDXL(animagine-xl-4.0、CreativeML Open RAIL++-M。生成物の公開・商用利用可)を用いたが、試行の結果、単一のプロンプトテンプレートでは品質が安定しないことがわかった。

- アイコン調テンプレートは「単一の物」には強いが、複数要素の場面がアイコンの寄せ集め(ステッカーシート状)に崩れる
- 場面調テンプレートは人物・情景に強いが、ふんわりした夢絵調に寄る
- 記号・文法用語・数式(♯、be動詞、解の公式など)は、どのテンプレートでも絵として描けない(文字を禁止しているため原理的に無理)

## Decision

### 3テンプレート生成 + 語ごとのベスト選定

全 1,090 語を 3 種類のテンプレート(v1: フラットアイコン調 / v2: 絵本調 / v3: 太輪郭のマットなフラット調)で生成し、**語ごとに3案を並べてAIレビューでベストを選ぶ**。選定基準は「主題が読み取れること」最優先、同点ならフラットでくっきりした案(ユーザーの好みに合わせる)。

- プロンプトは語・教科・説明文から教科別のAIエージェントが作成(文字が描けない前提で、数式→天秤、文書→白紙の巻物のように視覚要素へ置換)
- seed は語の SHA256 から決定的に導出(再実行で同じ絵)
- 3案とも不良だった語(229語)は下記の2通りで差し替える

### 記号・用語系はタイポグラフィカード(SD不使用)

3案不良のうち 156 語(音楽記号・文法用語・数式・曜日など)は、**記号・文字・短い式をプログラム描画したパステル調カード**にする(例: シャープ→「♯」、be動詞→「am is are」、変域→「0≦x≦5」)。pokemon の「配色と文字だけの型色カード」(ADR 00002)と同じ思想で、絵で描けないものは文字で正確に伝える。フォントは Noto CJK / Noto Music / Noto Sans Math。

残り 73 語(工具・縫い方など実物)は要素を1つに絞った単純プロンプトで再生成し、新旧をAI判定で比較して良い方を採用した(43語が再生成版、30語は旧版のまま)。

### 配布と表記

- 720x720 JPEG に縮小し、**画像内右上に「AIイメージ」(SD生成)または「イメージ」(カード)と明記**する(実写と誤認させない。他リストの概念イメージと同じ流儀)
- GitHub Release で配布: `gimukyoiku-image-v1`(563枚) / `gimukyoiku-image-v1b`(527枚)。1リリース1000アセット上限のため pokemon と同じハッシュ分割。アセットは CC0
- ファイル名は `gk_<sha1(語)先頭10桁>.jpg`(語由来なので、行の増減で id がずれても URL は安定)
- `image_page` はリリースのタグページ(ライセンス・AI生成明示の確認先)。`wikidata` 列は空のまま(Wikidata由来ではないため)
- CSV への適用は `tools/apply_gimukyoiku_ai_images.py`(実写がある行は触らない。冪等)。語→手法・プロンプトの対応は `tools/gimukyoiku_image_manifest.jsonl` に記録し、再生成の再現性を確保する

## Consequences

- gimukyoiku は全 1,867 行に画像が付く(実写 777 / SD生成 934 / カード 156)
- 生成画像の品質は一様ではない(特に抽象概念のSD絵は「雰囲気イメージ」にとどまる語がある)。差し替えたい画像は manifest のプロンプトを直して該当語だけ再生成すればよい
- 実写だけが欲しい利用側は、既存の慣習どおり `releases/download/gimukyoiku-image-` で始まる URL を除外すればよい
- 生成環境(GPU・SDXL)は本リポジトリの外にあるため、月次バッチには入れない。新規語の追加時は同じ手順を手動で回す
