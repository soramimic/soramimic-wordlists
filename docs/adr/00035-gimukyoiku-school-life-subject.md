# ADR 00035: gimukyoiku.csv に非教科の subject「学校生活」を置き、既定では含めない

- Status: accepted
- Date: 2026-08-02
- Supersedes: none
- Superseded by: none
- Related: 00022(gimukyoiku の収録基準。学校生活の一般語を収録しないと決めた) / 00034(level列と高校への拡張)

## Context

ADR 00022 は「学校生活の一般語・授業運営語は収録しない」と決めた。教科 facet の
意味が薄まる(プリント・暗記・ペアワークはどの教科でも成立してしまう)ためで、
この判断自体は今も正しい。

一方で、この種の語は**「習った!」ではなく「やった!」の共通体験**として通用度が
高く、空耳・替え歌の素材としては優秀でもある。運動会・徒競走・玉入れのような
行事の語がその典型で、実際 gimukyoiku には保健体育として混ざっていた。

そこで今回、教科の学習内容でない語を保健体育から外そうとしたが、徒競走や綱引き、
組体操は**体育の授業で実際に扱う運動**なので保健体育に紐づく。教科に紐づかず、
かつ落とすには惜しいのは運動会と応援合戦のような**行事そのもの**の語だった。

## Decision

**subject に非教科の区分 `学校生活` を1つ足し、教科に紐づかない学校の語をここに
入れる。ただしこの区分は既定では使わない。**

- ADR 00022 の「教科 facet を薄めない」という目的は、除外ではなく**別区分への
  隔離**でも達成できる。教科の9区分は教科の中身だけで構成されたままになる
- **既定で含めない**。利用側は `subject~=` で教科を明示して絞る前提とし、
  `学校生活` は使いたいときだけ明示的に足す。この既定は利用側(soramimic の
  setting.json)の設定なので、本リポジトリでは README に明記して伝える
- 教科の授業で実際に扱う活動は教科のまま置く。徒競走・玉入れ・綱引き・騎馬戦・
  大玉転がし・二人三脚・台風の目・組体操は体育の運動なので `保健体育`、
  応援合戦と運動会は行事なので `学校生活`

## Consequences

- subject の値が9区分から10個に増える。利用側で「全 subject を出す」実装に
  なっていると、意図せず学校生活が混ざる。README の注記だけが歯止めなので、
  soramimic 側の setting.json で除外されているかは別途確認が要る
- 「教科に紐づく活動か、行事か」の線引きに判断が要る。組体操(体育)と応援合戦
  (行事)のように近い語が別区分に分かれるので、迷ったら「その活動を体育や家庭科
  などの授業時間にやるか」で決める
- ADR 00022 で削除した授業運営語26語と、カタカナ英単語の削除とあわせて落とした
  授業運営語7語(スピーキングテスト・フラッシュカードなど)は、この区分の対象に
  なりうる。復活させるかは別の判断として行う(今回は復活させていない)
