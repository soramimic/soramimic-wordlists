# ADR 00022: youtuber.csv から成人向け業界の人物を職業(P106)で除外する

- Status: accepted
- Date: 2026-07-29
- Supersedes: none
- Superseded by: none
- Related: 00011(youtuber/vtuber リストの収録基準) / 00014(既存行を劣化させない)

## Context

youtuber.csv は「Wikidata の職業(P106)が YouTuber / バーチャルYouTuber で、
ja.wikipedia に記事がある人物」を機械的に収録している(ADR 00011)。この基準は
著名性の判定を Wikipedia に委ねられるのが利点だが、**業界を問わない**ので、
YouTube チャンネルを持つ AV女優・ポルノ俳優もそのまま入ってくる。実際に
996人中24人が該当していた(あべみかこ・天使もえ・明日花キララ・上原亜衣 等)。

この単語リストは soramimic-video の**サンプル単語リスト**として一般向けアプリの
UI に並ぶ。単語がランダムに提示される使われ方なので、成人向け業界の人物が
混ざっていると利用文脈に合わない。

既に `EXCLUDED`(記事名のベタ書き)で個別に6人を除外していたが、これは
「気付いた人だけを手で足す」運用で、Wikidata 側の追加に追随できない。

## Decision

**P106 に成人向け(アダルト)業界の職業を持つ人物は収録しない。**
除外職業の QID は `tools/update_youtuber.py` の `EXCLUDED_OCCUPATIONS` に置き、
`fetch_persons` の SPARQL で候補集合から落とす。

- AV女優(Q1079215) / AV男優(Q8380347) / AV監督(Q10846391) /
  ポルノ俳優(Q488111) / ポルノ映画監督(Q17456089) /
  アダルトモデル(Q3286043) / ヌードモデル(Q161850) /
  カムガール(Q1027930) / virtual webcam model(Q85521754) /
  ストリッパー(Q1141526) / 娼婦(Q14915751) / セックスワーカー(Q852857)
- **P106 は現職と元職を区別しない**ので、判定は「過去の職歴を含めて該当職業を
  持つか」になる。元AV女優も除外する。個々の活動実態を人が判定するより、
  機械的で再現可能な基準を優先する
- 除外した人物は名前を実行ログに出す(黙って消えると気付けないため)
- QID 取り違えのフェイルセーフとして、既存の `assert_occupation` を使って
  各 QID のラベルに期待キーワードが含まれることを実行前に確認する

### 除外しない境界事例

- **グラビアアイドル(Q1328668) / グラビアモデル(Q28692662)** は一般誌・一般
  メディアでの活動で、成人向け業界とは別カテゴリなので除外しない。現在32人が
  該当する(篠崎愛・柏木由紀・小倉優子・大原優乃 等)
- **ラウンドガール・ホスト・性教育者**も職業として成人向け業界ではないので
  除外しない
- **性犯罪者(Q5659979)** は職業ではなく経歴なので、この方針の対象外とする。
  刑事事件を理由とする個別除外は [ADR 00065](00065-youtuber-criminal-case-exclusions.md)
  の基準で判断する

### P106 に登録が無い取りこぼし

Wikidata の P106 が不完全なケースは機械的に弾けないので、従来どおり `EXCLUDED`
(記事名)に理由コメント付きで足す。今回は ja記事の冒頭が「グラビアアイドル、
ヌードモデル、モデル、タレント」で P106 にヌードモデルが無い1人が該当した。

## Consequences

- youtuber.csv は 2078行(996人) -> 2020行(972人)になる。24人・58行の削除
- `EXCLUDED` から6人(アレクシス・フォウクス / ミア・ハリファ / リサ・アン /
  ルビィ・デイ / 佳苗るか / 小宵こなん)を消せる。職業フィルタが同じ人を
  構造的に弾くので、記事名のベタ書きは不要になった
- **トレードオフ: 過去に一度でも該当職業が付いた人は、現在の主活動が別分野でも
  除外される**。P106 に期間の情報が無い以上、元職を見分けるには人手の判定が
  要る。網羅性より方針の明確さと再現性を採る
- **トレードオフ: Wikidata の P106 の網羅性に依存する**。該当職業が登録されて
  いない人物は素通りする。気付いたら `EXCLUDED` に足して補う
- 削除した24人のうち10人には生成済みの象徴カード SVG が `images/youtuber/` に
  残る。`python3 tools/gen_youtuber_cards.py --prune` で削除できる
  (カードの再生成PRと衝突しないよう、本PRでは画像ファイルに触っていない)
- 利用側(soramimic-video)は submodule の参照を進めれば反映される
