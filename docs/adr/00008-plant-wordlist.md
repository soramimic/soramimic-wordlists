# ADR 00008: plant(植物)ワードリストの新規作成と自動更新

- Status: accepted
- Date: 2026-07-11
- Related: 00007(sekitsui の自動更新。本リストはその設計を植物に踏襲) / 00015(画像・分類補完を月次バッチに入れず手動実行とする扱い)
- Superseded by: 00014-no-degrading-existing-rows.md(既存行の class/extinct を毎回取得結果で上書きする判断のみが置き換え)

## Context

動物(脊椎動物)の網羅リスト sekitsui(ADR 00007)に続き、植物の和名リストを新設する。sekitsui と同じく `surface = pronunciation = カタカナ和名` の構造なので、人名リスト(ADR 00005)で必要だった「記事冒頭文からの読み抽出」は不要で、Wikidata の日本語ラベルがそのまま答えになる。

植物は脊椎動物(約7,280種)と規模の桁が違う。被子植物だけで数十万種あり、Wikidata の SPARQL で被子植物 Q25314 を一括クエリすると WDQS がタイムアウトする。一方、カタカナ和名を**持つ**種に絞ると規模は現実的になる。事前調査(2026-07-11 時点)での実測は次の通り:

- 被子植物: 60 目に分割して取得し計 **6,025 種**(TIMEOUT なし)。上位はキク目540・イネ目499・シソ目448・キジカクシ目428・バラ目396
- 裸子植物 99、シダ植物 216(Pteridophyta 215 + 誤 QID Q157819 由来のセイヨウカノコソウ 1)、コケ植物 101(蘚類62・苔類37・ツノゴケ類2)、藻類 114(紅藻38・褐藻41・緑藻23・車軸藻7・珪藻5)
- 合計 **約6,500 種**。sekitsui(7,280)に匹敵する網羅リストになる

## Decision

Wikidata を出典に `tools/update_plant.py` の年次バッチで未収録の種を追記する。ADR 00001 の4基準(機械可読な構造化データ / 認証不要 / CC0 / 差分追記)を満たし、sekitsui と同じ差分方式(既存行の表記・id は書き換えず、未収録の和名だけ id 連番で追記)を採る。

- 対象は **rank=種(Q7432)** で **日本語ラベルがカタカナのみ**の taxon。カタカナ以外(漢字ラベル、曖昧さ回避付き)は既存リストの性格に合わないので除外する
- **`class` 列に大分類(双子葉 / 単子葉 / 裸子植物 / シダ植物 / コケ植物 / 藻類)を持たせる**。被子植物は数が支配的なので、利用側のバランス取りのため双子葉/単子葉に細分する。双子葉は現代分類では多系統だが、伝統的な2分類として運用する
- **被子植物は目(order)ごとに分割クエリする**。被子植物 Q25314 の一括クエリはタイムアウトするため。目の一覧は実行時に Wikidata から取得(`?o wdt:P171* wd:Q25314 ; wdt:P105 wd:Q36602`)し、単子葉植物 Q78961 配下の目を「単子葉」、それ以外を「双子葉」に振り分ける。目単位ならタイムアウトしないことを実測で確認済み(最大のキク目540種でも可)。目一覧を実行時取得にすることで、APG の目の増減に追随できる
- **非被子植物は正式な門・綱の QID を直接指定**して取得する。コケ植物 Q29993・藻類 Q37868 は Wikidata 上で非公式グループであり P171 の親タクソンにならない(配下の種が 0 件になる)ため、門ごとに分けて束ねる:
  - 裸子植物 Q133712
  - シダ植物 = Pteridophyta Q178249 + 小葉植物 Lycopodiophyta Q215370(当初 Q157819 と誤記していた。実体は Valeriana officinalis で、この行は事実上セイヨウカノコソウ1件を引くだけだった)
  - コケ植物 = 蘚類 Q25347 + 苔類 Q189808 + ツノゴケ類 Q191156
  - 藻類 = 紅藻 Q103169 + 緑藻 Q264543 + 褐藻 Q184573 + 珪藻 Q9642991 + 車軸藻 Q133219
- **化石種・絶滅種も含める**。判定は sekitsui と同じで、IUCN ステータス(P141)が絶滅種(Q237350)/野生絶滅(Q239509)、または instance of(P31)が化石タクソン(Q23038290)のいずれか。`extinct` 列(yes/no)で区別する
- 取得総数が下限(4,000)を下回ったら取得失敗とみなして中断する(実測 約6,500 に対する妥当性ガード)
- **非植物の混入は2段構えで防ぐ**。ADR 00014 の動物界ガード(新規候補の `P171*` が動物界 Q729 に到達したら追加しない)は「誤リンクが動物界まで繋がっている」場合しか落とせない。次の2パターンはすり抜けるので、`tools/update_plant.py` の `EXCLUDED`(除外理由をコメントで併記)に和名を列挙して恒久除外する。CSV から消すだけでは翌回の自動更新で再追加されるため
  1. **植物の taxon に動物の日本語ラベル/sitelink が付いている**(例: Senna versicolor Q15537572 に「セモンジンガサハムシ」= ハムシ科の昆虫)。系統は完全に植物なので動物界に到達しない
  2. **動物の taxon の親タクソンが異物同名(homonym)の植物・藻類の属になっている**(例: カンブリア紀の葉足動物 Microdictyon sinicum Q15104318 が緑藻の属 Microdictyon 配下)。系統を辿ると植物側に出る
- **棚卸しでは `CLADES` の QID 自体も検証する**。QID の取り違えは件数が 0 や 1 になるだけで妥当性ガード(下限4,000)にも引っかからず、静かに丸ごと取りこぼす(実例: ヒカゲノカズラ植物のつもりの Q157819 が実際は種 Valeriana officinalis だった)。棚卸し時は `CLADES` と定数(Q7432/Q36602/Q25314/Q78961/Q729/Q237350/Q239509/Q23038290)の全 QID について **日本語・英語ラベル / 分類学名 P225 / rank P105** を引き、コメントの想定と一致するかを確認する
- **全量の棚卸しは `tools/audit_plant_taxa.py`** で行う。CSV の全和名について QID 解決 → 上位タクソン(`P171*`)の到達判定 → description(en/ja)の語彙照合を通し、要確認リストを出す。自動削除はせず、実体確認のうえで削除+`EXCLUDED` 追加を人(またはエージェント)が行う。ガードは新規候補にしか効かないので、既存行の混入はこの棚卸しでしか見つからない
- **和名が植物と動物で同音異義になっているだけの行は残す**(スギ・サワラ・ハス・ヒイラギ・カマツカ・ホトトギス等)。植物側の taxon が実在するなら植物の和名として正しい

### 画像(image / image_page / wikidata)

sekitsui(ADR 00007 / 00015)と同じく、Wikidata の P18(画像)から Wikimedia Commons の写真を付与する。付与は `tools/enrich_plant_images.py`。

- **同名異義ガードは「クエリの起点」で効かせる**。植物には動物と同じ和名を持つものが多い(スギ・ハス・ホトトギス・カマツカ等)ので、和名で名寄せする前に取得範囲を植物側に閉じるのが要点になる。`update_plant.py` と同じ取得単位(被子植物は目、非被子植物は門・綱)を起点に `?t wdt:P171* wd:<起点>` で引くので、そもそも動物側の taxon が候補に入らない。「和名から QID を引いてから界を判定する」順序にすると、同名の動物を先に拾って植物の行に動物の写真を付けてしまう
- 起点を植物に閉じても、Wikidata の系統樹には界をまたぐ誤リンクがあり動物が植物の目の配下として引けることがある(実例: ヘビトンボ Q2481303)。そこで書き込み直前に `update_plant.py` と同じ動物界ガード(候補 taxon の `P171*` が Q729 に到達するか)をもう一段かけ、全候補が動物到達なら画像を付けない
- `wikidata` 列には画像の取得元になった taxon の QID を入れる。sekitsui と同じく画像とセットで埋まる列とし、画像が取れなかった行は3列とも空のままにする(利用側は空でも動くこと)
- 付与率は初回実行(2026-07-28)で **5,799/6,542 行 = 88.6%**(sekitsui は 83%)。分類群ごとに偏りがあり、裸子植物 97% / 単子葉 90% / 双子葉 89% / シダ植物 86% に対し、コケ植物 64% / 藻類 63% と低い。コケ・藻類は Commons に種単位の写真が少なく Wikidata の P18 が未設定な taxon が多いためで、異常ではない。妥当性ガード(`MIN_TOTAL`)はこの実測値を基準に置く
- **月次バッチ(update-wordlists.yml)には入れず手動実行とする**(`enrich_sekitsui_images.py` と同じ扱い、ADR 00015)。取得対象が70件超の目・門に分かれていて全体で30〜60分かかり、他の updater が並ぶ月次バッチに載せるには重すぎる。月次で増える新規種は数十件規模なので、画像はまとめて手動で補完すれば足りる
- 目・門ごとの取得結果は `tools/.cache/`(Git 管理外)に逐次保存し、中断しても再実行で続きから再開できるようにする(全件引き直しは `--refresh`)

## Consequences

- plant が pokemon / nations / stations / baseball / football / physicist / sekitsui に続く自動更新対象になる
- 藻類は多系統で、上記5門で網羅しきれない(渦鞭毛藻・ハプト藻など単細胞群の一部は漏れる)。網羅リストへの追記運用なので、取りこぼしは将来 `CLADES` に門を足して補える
- 双子葉/単子葉の判定は目の所属に依存する。Wikidata で単子葉植物 Q78961 配下に置かれる目(サトイモ目・ホンゴウソウ目を含む)を単子葉とする。将来 APG の再編で目の所属が変われば追随する
- 被子植物の目の QID・所属が変わってタイムアウトや件数急減が起きた場合は、妥当性ガード(下限4,000)で検出される。特定の目が将来巨大化してタイムアウトするなら、その目を科(family)単位に細分する
- 追記のみで、既存の和名の削除・改名の反映はしない(網羅リストへの追記として運用)
- 画像は手動実行なので、月次バッチで追記された新規種はしばらく画像が空のままになる。利用側は `image` が空の行を許容すること
- 画像の値はスナップショットであり、Commons 側の画像差し替え・削除には自動追従しない。既に埋まっている行は再実行しても更新されない(冪等)ので、引き直したいときは `--refresh` ではなく該当列を空にしてから実行する
