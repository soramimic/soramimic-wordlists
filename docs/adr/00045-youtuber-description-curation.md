# ADR 00045: YouTuber説明文を活動内容中心の短文にする

- Status: accepted
- Date: 2026-08-09
- Related: [00029](00029-youtuber-channel-description-columns.md)(channel / description列)

## Context

`youtuber.csv` の description は、以前は scientist と同じく Wikipedia 冒頭を
90字程度まで連結していた。その結果、所属・出身地・登録者数などカードの別列と
重複する情報や、記事冒頭の文脈に依存した長い説明が残りやすかった。

## Decision

1. YouTuber/VTuber専用の生成処理を `tools/yt_common.py` に置く。新規追加時にも
   同じ処理を使い、scientist の説明生成には影響させない。
2. description は目安50字、通常の上限65字とする。ただし内容を壊す切断はせず、
   安全な完結文が長くなる場合は例外を許す。
3. 肩書きだけでなく、動画・配信・ゲーム実況・音楽・料理・教育・慈善活動などの
   具体的な活動、受賞・記録・代表的な企画を優先する。
4. 登録者数・再生回数などの時変値、所属・会社情報、出身地・家族関係、本名、
   「同年には」「その後」「彼は」などの文脈依存表現は説明から外す。名前はカードに
   別表示されるため、冒頭の冗長な主語も外す。また「日本のYouTuber」のような
   地域＋一般肩書きはカード種別と重複するため外し、活動テーマや別の肩書きを残す。
   「日本で活動する中国人」のように地域性自体が識別情報になる場合は例外とする。
5. 既存行の一括更新は `tools/enrich_youtuber_descriptions.py --refresh` で明示的に
   行う。通常の `update_youtuber.py` は従来どおり既存値を劣化させず、新規行と空欄
   の説明にこの生成処理を使う。
6. `soramimic-video` の `youtuber_card` は選手カードと同じ写真左・情報右の構成にし、
   右側を名前、所属、デビュー年、description の順にする。

## Consequences

- 説明文だけで活動の種類が分かりやすくなり、登録者数の更新で説明まで変わらない。
- 記事冒頭に活動内容が無い人や、グループ記事へのリダイレクトは `NA` または短い
  グループ説明になる。自動抽出で判断しにくい行は、レイアウト確認時に手動監査する。
