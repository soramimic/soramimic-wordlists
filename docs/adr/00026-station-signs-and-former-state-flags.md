# ADR 00026: stations は汎用の駅名標で埋め、消滅した国には当時の旗を付ける

- Status: accepted
- Date: 2026-07-29
- Supersedes: none
- Superseded by: none

## Context

画像が空のまま残っていた行は、scientist(ADR 00025)のほかに2か所あった。

- **stations.csv**: 9,467行のうち160行。路面電車の電停・索道の駅・私鉄の小駅など、
  Commons に自由ライセンスの写真が無い駅である
- **nations.csv**: 398行のうち16行。ソ連・ユーゴスラビア・チェコスロバキア・東西ドイツと、
  現在の国の旧称であるセイロン・ザイール・ビルマ。いずれも `status=former` の行

理由はそれぞれ違う。

駅の写真は「撮りに行けば増える」が、このリポジトリが自動で増やせるものではない。
一方、駅には**駅名標**という、駅そのものを指す看板がある。写真の代わりにこれを描けば、
1枚絵として成立する。

国旗の方は取得側の問題だった。`tools/enrich_nation_flags.py` は
`tools/nations_map.csv`(cca3 -> id)経由で Wikidata を引くが、**消滅した国には
ISO 3166-1 の cca3 が無い**ので、この経路では1件も引けなかった。旗そのものは Commons に
あり、しかも国旗はほぼすべてパブリックドメインである。

## Decision

### 1. stations: どの鉄道会社のものでもない、汎用の駅名標を描く

`tools/gen_station_signs.py`。生成物は `images/station/`、CSVからは raw URL で参照する。

- **実在の鉄道会社の意匠は使わない。** ロゴ・社章・駅ナンバリングの丸・専用書体・
  ラインカラーの再現はしない。白地の板に駅名とかな読みを置き、上下に帯を敷き、
  板を支える柱を2本描いた、どこの会社のものでもない看板にする。
  JR風・私鉄風に寄せることもしない
- 実写と誤認されないよう右上に「イメージ」の札を入れる(他の生成画像と同じ)
- **帯の色は路線名(`lines` の先頭)のハッシュから決める。** このリポジトリは路線の実カラーを
  持っておらず、推測で塗るのは実在のラインカラーの再現になってしまうため。原色は避けて
  彩度・明度を落ち着いた範囲に固定し、色相だけを振る。**同じ路線の駅が同じ色になる以上の
  意味は無い**。`lines` が空の行は都道府県、それも空なら駅名から振る
- **1行1枚**(人物リストのように名前で共有しない)。同じ「神戸三宮」でも阪急と阪神は
  別の駅で、別の行として存在するため。ファイル名の元にする文字列は Wikidata QID、
  無ければ 駅名・都道府県・市区町村・路線 をつないだもの
- 写真がある行は**絶対に触らない**。冪等

### 2. 駅名標には駅名を書く(ADR 00024 の例外)

ADR 00024 で「カードに文字を描かない」と決めたのは、soramimic-video のレイアウトが
同じ文字をテキストで描くため、画面内で二重になるからだった。駅名標はこの例外とする。

- **駅名標は駅名が書かれていて初めて駅名標である。** 名前を消すと160駅すべてが同じ
  白い板になり、1枚絵として何も語らない
- 実写の駅写真にも駅名標は写っていて、同じ文字が画面に出る。生成画像だけ文字を抜くと、
  写真のある駅とない駅で見え方の性格が変わってしまう
- `station_card` レイアウトは画像の**外**に駅名・都道府県・路線を描くので、文字同士が
  重なることもない(選手カードで問題になったのは、カード内の文字とレイアウトの文字が
  同じ領域で二重に見えることだった)
- 文字サイズは幅から機械的に決める。長い駅名(最長21文字)は縮めて板に収める

### 3. nations: 消滅した国は Wikidata の item を直接指し、**最後に使っていた旗**を選ぶ

`tools/enrich_nation_flags.py` に `FORMER_STATES`(行の表記 -> QID)を足した。

- cca3 が無い国はここで item を指す。`nations_map.csv` は cca3 の対応表なので、
  ISOコードを持たない国を混ぜない
- **消滅国・旧称の行を cca3 より先に見る。** セイロン・ザイール・ビルマの行は現在の国
  (スリランカ・コンゴ民主共和国・ミャンマー)と同じ id にぶら下がっているので、
  cca3 から引くと現在の旗が付いてしまう
- **同じ id でも表記ごとに指す item が違う。** ユーゴスラビアは王国(1918-1941)と
  社会主義連邦共和国(1943-1992)で旗が別物なので、「ユーゴスラビア王国」の行に赤星の旗を
  出すのは誤り。総称の「ユーゴスラビア」だけは通史の item を指す
- 旗は truthy値(`wdt:P41`)ではなく文(`p:P41`)を順位・適用期間ごと取り、
  (1) 廃止ランクを捨てる (2) 優先ランクがあればそれだけに絞る (3) 適用終了(P582)が
  最も新しいものを採る (4) 並んだらファイル名順、で1つに決める。ソ連は6つある候補から
  1955-1991年の旗が選ばれ、東ドイツは国章入りの旗(1959年以降)になる
- チェコスロバキアの P41 は `Flag of the Czech Republic.svg`(現チェコが同じ旗を
  引き継いだため)を指す。意匠も作者もPDの扱いも同じ `Flag of Czechoslovakia.svg` が
  Commons にあるので、**クレジット先のページ名が誤解を招かないよう**そちらに差し替える
  (`FILE_OVERRIDE`)
- 付与した16行の旗はすべて Commons で **Public domain**(国旗の意匠は多くの法域で
  著作権の対象にならない)。`image_page` から個別に確認できる

同時に、このスクリプトが列をヘッダーから読まず固定リストで書き戻していた不具合も直した
(`pronunciation` 列が後から増えていたため、実行すると列が落ちて壊れる状態だった)。

## Consequences

- stations.csv の全9,467行、nations.csv の全398行に画像が入り、空欄が無くなった
  (駅160行に160枚、国16行に8種の旗)
- 駅名標は Material Symbols を使っていないので、**この画像に Apache License 2.0 の
  帰属義務は生じない**(scientist/baseball/football/youtuber のカードとは違う点)
- 帯の色は**このリポジトリが機械的に決めた色**であって、路線のラインカラーではない。
  外部で「この路線の色は緑」と参照されると誤りになるので、生成器のコメント・SVGの
  `<desc>`・本ADRに明記した。将来 `lines` に実カラーの出典が付いたら差し替えられる
- 駅名標は文字を含むぶん、レンダリング環境のフォントに依存する。文字幅は東アジア文字を
  全角として多めに見積もり、**はみ出すより小さく出る側**へ倒している
- 生成は決定的(2回実行してバイト一致)、CSVの適用は冪等
- 消滅国の旗は「最後に使っていた旗」なので、ソ連の行は1922-1955年の旗ではない。
  別の時代の旗を出したい利用側は `wikidata` 列の QID から自分で選べる
