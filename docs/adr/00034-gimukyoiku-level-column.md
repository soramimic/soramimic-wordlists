# ADR 00034: gimukyoiku.csv に level 列を足し、高校の用語まで収録範囲を広げる

- Status: accepted
- Date: 2026-08-02
- Supersedes: none
- Superseded by: none
- Related: 00022(gimukyoiku リストの新規作成。subject 区分と収録基準) / 00009(facet列の前例)

## Context

gimukyoiku.csv は「義務教育(小中学校)の教科書・授業に登場する語」として作った
(ADR 00022)。運用してみると二つの不足が見えた。

1. **小学校の語と中学校の語が混ざっていて絞り込めない**。「九九」「おおきなかぶ」
   のような小学校の語と、「因数分解」「電磁誘導」のような中学校の語が同じ
   subject に同居している。利用側(soramimic)で対象年齢に合わせて出し分けたくても
   軸が無い。
2. **高校の語が丸ごと落ちている**。「習った!」という共通体験を素材にするのが
   このリストの狙い(ADR 00022)だが、その体験は義務教育で終わらない。微分・積分、
   モル、細胞小器官、諸行無常の高校版といった語は通用度が高いのに入っていない。

## Decision

**`level` 列(小学校 / 中学校 / 高等学校)を subject の直後に追加し、収録範囲を
高校の教科書に登場する語まで広げる。**

### level 列

- 値は `小学校` `中学校` `高等学校` の3つだけ。**その語が初めて本格的に扱われる
  学校段階**を入れる
- 複数段階で本格的に扱う語(比例、都道府県、光合成など)は subject と同じく
  `/` 区切りの多値にし、`level~=小学校` の部分一致で絞り込む。順序は
  小学校 → 中学校 → 高等学校 に正規化する
- 学年(小1〜高3)までは持たない。教科書会社ごとに学年配当が違う語が多く、
  恣意的になるうえ facet 軸として細かすぎるため

### ファイル名は gimukyoiku.csv のまま

高校を含むと名前と中身がずれるが、リネームは利用側(soramimic の setting.json と
submodule 参照)の追随コストに見合わない。README とこの ADR に「小中の語を中核に、
高校の語も level=高等学校 で収録する」と明記して名前の由来を残す。

### 高校の科目は既存の subject 9区分に寄せる

高校では科目が細分化される(数学I〜III・A/B/C、物理基礎、地理総合、公共 など)が、
subject は ADR 00022 の9区分
`国語 / 社会 / 数学 / 理科 / 英語 / 音楽 / 美術 / 保健体育 / 技術・家庭` のまま
運用する。区分が増えると利用側の絞り込み軸として細かすぎるという 00022 の判断は
高校を足しても変わらない。対応は次のとおり。

| 高校の科目 | subject |
|---|---|
| 現代の国語・言語文化・古典探究・論理国語 等 | 国語 |
| 地理総合/探究・歴史総合・日本史探究・世界史探究・公共・政治経済・倫理 | 社会 |
| 数学I〜III・数学A/B/C | 数学 |
| 物理基礎/物理・化学基礎/化学・生物基礎/生物・地学基礎/地学 | 理科 |
| 英語コミュニケーション・論理表現 | 英語 |
| 芸術(音楽) | 音楽 |
| 芸術(美術・工芸・書道) | 美術 |
| 保健体育 | 保健体育 |
| 家庭基礎/総合・情報I/II | 技術・家庭 |

書道は9区分に対応する枠が無いが、中学までの「書写」が国語である一方、高校の
書道は芸術科なので、教科としての連続性をとって美術に寄せる。

### 収録基準(高校ぶん)

ADR 00022 の基準を引き継ぐ。すなわち必修・共通履修の科目に出る定番語を厚めに
収録し、特定の教科書会社にしか載らない語や大学以降の内容は入れない。専門学科
(工業・商業・農業など)の科目は対象外とする。

## Consequences

- 列が1つ増えるので、利用側は列位置ではなくヘッダ名で読む必要がある(既存の
  パーサは素朴な split(",") なので、列追加時の追随が要る)
- 既存行の level は語ごとの判断で後から付けたもので、教科書の学年配当を機械的に
  引いたものではない。誤りは PR で修正する
- 「義務教育」という名前と実際の収録範囲がずれる。README の一覧表と本 ADR で
  補うが、リストを初めて見る人には分かりにくさが残る
- 高校ぶんを足すと行数が大きく増える。画像(ADR 00027/00028)の付与も同じだけ
  必要になるので、語の追加と画像の付与は別 PR に分ける
