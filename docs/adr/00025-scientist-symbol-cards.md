# ADR 00025: scientist の実写が無い行に分野色の象徴カードを割り当てる

- Status: accepted
- Date: 2026-07-29
- Supersedes: none
- Superseded by: none

## Context

scientist.csv は6,450行のうち556行(289人)に画像が無かった。ソラミミ動画は単語ごとに
1枚絵を出すので、画像が無い行だけ他のリストと同じ見せ方ができない。

科学者は歴史上の人物が多く、肖像画・肖像写真が Commons にある人は多い。それでも埋まらない
289人は「近現代の研究者で、自由ライセンスの肖像が存在しない人」が中心である
(内訳は 天文学143行・物理92行・数学89行 など)。本人の写真は本人・撮影者・所属機関の
権利物で、引用の要件も満たさないので、**残りを実写で埋める道は無い**。

一方、このリストには `field`(分野。スラッシュ区切りの多値)・`nobel`・`type`(family/full)
という材料がある。分野は事実であり、色や図形に写すことは誰の権利物の複製にもならない。
すでに youtuber(ADR 00018)・baseball/football(ADR 00020)で「実写が無い人には配色と
頭文字と汎用アイコンだけのカードを割り当てる」という前例と道具立て(`tools/silhouettes.py`,
`tools/material_icons.py`)がある。

## Decision

### 1. 実写が無い人にだけ、分野の配色で描いたカードを作る

`tools/gen_scientist_cards.py`。既存の生成カードと同じ約束に従う。

- **1人1枚**。同じ人物の family/full 行は同じ `original` なので1枚を共有する
- **実写がある人のカードは作らない**(使われないSVGをリポジトリに残さない)
- ファイル名は名前から決定的に導く `sc_<sha1(original)の先頭10桁>.svg`。
  id は将来の再採番に耐えないので使わない
- 実写のある行は**絶対に触らない**。冪等で、2回目以降の実行はCSVを書き換えない
- 生成物は `images/scientist/` に置き、CSVからは raw URL で参照する
  (1枚2〜3KBのSVGなので、Releaseを介さずCSVと同じコミットに入れる。ADR 00018 と同じ判断)

### 2. 配色は分野。ただし**出典のある色ではない**ことを明記する

選手カードの配色は「公表されたチームカラー」という事実に裏打ちされていた(ADR 00020)が、
**学問分野に公式の色は存在しない**。ここで割り当てる色は、7分野が並んだときに互いを
見分けられるようにするための**分類の手がかり**でしかない。

- 物理=青 / 化学=橙 / 数学=紫 / 天文学=夜空の濃紺 / 生物学=緑 / 計算機科学=青緑 /
  地学=土の茶(`FIELD_STYLE`)
- `物理/数学` のようなスラッシュ多値は**先頭を主分野**として帯に使い、2つめの分野の色を
  帯下のラインに回す。3つめ以降は描かない(細い帯を3本引いても読み取れない)
- `field` が空・`NA`・未知の値のときは既定の無彩色寄りの配色にし、**分野アイコンは敷かない**。
  嘘の分野を描くくらいなら何も描かない

### 3. 分野は文字ではなく**分野アイコン**で示す

ADR 00024 のとおり、カードには名前・分野・国の文字を描かない(soramimic-video の
`scientist_card` レイアウトが名前・生年・国・業績をテキストで描くので、カードにも入れると
画面内で二重になる)。文字の代わりに Material Symbols(Apache License 2.0)の図を
地紋として敷く。

- 職業アイコンと違い、**人型は使わない**。科学者のカードで区別したいのは「どんな人か」
  ではなく「どの分野か」で、人型を敷くと分野によらず同じ図になってしまう。
  研究対象・道具そのものの図を敷く
- 職業アイコンは「人型 x 役割マークのスロット」で図を散らしていたが、分野アイコンには
  その軸が無い。代わりに**1分野につき6個の図のプール**を持ち、人物IDのハッシュで1つ選ぶ
  (物理なら orbit / bolt / waves / speed / vibration / blur_on)。そのうえで左右反転・
  微小な回転・上下オフセット・±10%の拡縮が掛かるのは既存のカードと同じ。
  6図 x 反転で知覚12通り、さらに回転・上下・拡縮が乗る
- 割り当ては `tools/gen_material_icons.py` の `ROLES` に `field_*` として足し、
  `tools/material_icons.py` を再生成した。**既存6役割の出力は1バイトも変わっていない**
  (追加のみの差分)ので、既に配布済みの13,559枚のカードは再生成の影響を受けない
- 実在の研究機関・学会・企業のロゴやマークは使わない

### 4. 頭文字は姓から取る

中央のディスクに置く1文字は、`type=family` の行の `surface`(=姓)の先頭から取る。
`original` の先頭から取ると「チャールズ・キッテル」が「チ」になり、人物の手がかりとして
弱いため。姓の行が無い人(24人)は `original` の先頭を使う。

### 5. ノーベル賞受賞者だけ右下に星を置く

`nobel=yes` の行にだけ、自作の5芒星を白丸に載せて右下に置く。選手カードの競技ボールと
同じ位置・同じ大きさで、カードの家族としての見た目を揃える。
**ノーベル財団のメダルの意匠・エンブレム・名称は使っていない**(半径の比だけで作図した
ごく一般的な星形である)。

## Consequences

- scientist.csv の全6,450行に画像が入り、空欄が無くなった(556行に289枚を割り当て)。
  実写がある5,894行は一切触っていない
- 生成は決定的で、2回実行してもバイト単位で同じSVGが出る。CSVの適用も冪等
- カード画像には Material Symbols が含まれるので **CC0 ではない**。Apache License 2.0 の
  帰属が必要で、各SVGの `<desc>` にも1行入れてある(ADR 00024 と同じ扱い)。
  README の「利用上の注意」に `images/scientist/` を追記した
- 分野の色は**このリポジトリが決めた色**であり、学問分野を表す標準的な配色ではない。
  外部で「物理の色は青」と参照されると誤解になるので、生成器の定数と本ADRに明記した
- 実写だけが欲しい利用側は、従来どおり
  `https://raw.githubusercontent.com/soramimic/soramimic-wordlists/` で始まるURLを除外すれば
  生成カードを落とせる
- 将来 Commons に肖像が増えたら、`image` が空でなくても生成カードのURLなら貼り替え対象に
  できる(実写を優先する `enrich_*_images.py` 相当のスクリプトは scientist にはまだ無く、
  必要になった時点で足す)
