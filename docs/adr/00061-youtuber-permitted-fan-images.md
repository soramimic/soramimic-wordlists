# ADR 00061: ガイドライン確認済みVTuberファンメイド画像

- Status: superseded
- Date: 2026-08-17
- Related: [00018](00018-youtuber-images.md) / [00019](00019-youtuber-derived-colors.md)

## Context

VTuberの多くは自由ライセンスの人物写真を持たないため、従来は本人の配色と文字から
作った象徴カードを表示していた。一方、一部の運営は、無料公開した公式静止画を用いた
非営利の二次的創作物について公式ガイドラインを公開している。

## Decision

次の条件をすべて満たす画像に限り、象徴カードを上書きできるようにする。

1. 個人の非営利ファン活動として利用可能であることを、運営の現行公式ガイドラインで
   確認している
2. 公式立ち絵そのものではなく、背景、構図、配色、非公式表示を組み合わせて制作し、
   全画像を目視確認している
3. 画像内に非公式ファンメイドであることと権利者表記を入れる
4. `tools/youtuber_permitted_images.json` に公式プロフィール、元画像、ガイドライン、
   確認日、権利者表記、元画像と完成画像のSHA-256を保存する
5. `youtuber.csv` の `image_credit` に権利者表記を保持し、動画のクレジットにも表示する。
   `image_usage=noncommercial_fanwork` と公式ガイドラインURLも同じ行に保持し、利用側は
   既定で拒否して明示的な非営利モードでのみ使用する
6. 台帳にない画像、ハッシュが異なる画像、対象人物・所属が一致しない画像、
   Commons実写等を上書きしようとする画像は検証で拒否する

初回対象は、現所属が確認できるあおぎり高校11人とななしいんく1人の計12人である。ホロライブは別作業の
対象なので本変更には含めない。

その後、確認対象を主要な2社に絞るため、この12人への適用を停止して象徴カードへ
戻した。台帳と検証機構は、判断を追跡可能な形で保持する。

適用順は「人物更新 → 象徴カード生成 → レビュー済み画像適用」とする。これにより、
月次更新で象徴カードへ戻らず、台帳を削除すれば安全な象徴カードへ戻せる。

## Usage conditions

本画像は非営利用途向けであり、自由ライセンス素材ではない。利用時は
`image_credit` を表示し、公開前に `image_terms_page` から現行条件を確認する。
公式ガイドラインが変更された場合は対象画像を台帳から外し、象徴カードへ戻す。
