# ADR 00044: 架空アニメキャラの弱い肖像を5x5生成で段階的に置き換える

- Status: accepted
- Date: 2026-08-08
- Supersedes: none
- Superseded by: none
- Related: 00010

## Context

`fictional_anime_character.csv` と `fictional_daily_anime_character.csv` が参照する
架空キャラクター肖像2025枚を、キャラクター設定との整合性と描画品質の観点から
全件再QCした。判定結果は次のとおりだった。

- ok: 1597枚
- weak: 325枚
- ng: 103枚

`weak` は、顔・手指・塗りの軽い崩れや、年齢・服装・毛色などの軽い設定不一致が
あるものとした。`ng` は、顔や身体の明確な破綻、人物の融合、文字化け、または
性別・年齢・職業・種族などが設定と明確に矛盾するものとした。

428枚を個別生成するとWeb版ChatGPTの画像生成上限を大きく消費する。一方、この
リストの肖像は高精細な鑑賞画像ではなく、キャラクターを識別できる正方形画像で
あればよいため、1枚に複数キャラクターを配置して切り出す方法が適している。

## Decision

`weak` と `ng` の両方を再生成対象とし、1枚を5行5列に等分した25キャラクターの
グリッドとして生成する。

- 各セルは白背景、単独の全身またはポートレート、文字なしとする
- 名前、説明、役割、種族、旧画像の不合格理由をセルごとの指示に含める
- 年齢、性別、職業、種族、服装、毛色、持ち物を設定どおり明瞭に描かせる
- 生成後は境界を内側へトリムし、各セルを720x720 JPEGへ変換する
- グリッド全体をコンタクトシートで確認し、人物混在、枠ずれ、明確な破綻がない
  ものだけを採用する
- 既存のファイル名とURLを維持し、GitHub Releaseへ同名上書きする

今回、10グリッドから228枚を採用した。

| リスト | weak | ng | 合計 | 配布先 |
|---|---:|---:|---:|---|
| 架空日常 | 81 | 27 | 108 | `fictional-daily-anime-character-v2` / `v2b` |
| 架空ファンタジー | 99 | 21 | 120 | `fictional-anime-character-v2` |
| 合計 | 180 | 48 | 228 | |

Release上の全228アセットについて、アップロード後のファイル名とバイトサイズを
ローカル採用品と照合した。CSVのURLは変わらないため、CSV自体は変更しない。

残る200枚（weak 145 / ng 55）は、両ChatGPTセッションで画像生成が完了しない
状態になったため、生成枠の二重消費を避けて今回は保留する。

## Consequences

- 明確な設定矛盾を含む48枚と、品質の弱い180枚が改善される
- 5x5方式により、228枚を10回の成功した画像生成で置き換えられる
- 1セルの生成解像度は約250x250となるが、識別用肖像として必要な品質は満たす
- 残る200枚は同じQC基準と生成方式で後続作業を再開できる
- 高精細化よりも、設定整合性と生成枠の効率を優先する
