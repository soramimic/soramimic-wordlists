# ADR 00044: 架空アニメキャラの弱い肖像をグリッド生成で置き換える

- Status: accepted
- Date: 2026-08-08
- Supersedes: none
- Superseded by: none
- Related: 00010

## Context

`fictional_anime_character.csv` と `fictional_daily_anime_character.csv` が参照する
架空キャラクター肖像2025枚を、キャラクター設定との整合性と描画品質の観点から
全件再QCした。判定結果は次のとおりだった。

- ok: 1597枚
- weak: 325枚
- ng: 103枚

`weak` は、顔・手指・塗りの軽い崩れや、年齢・服装・毛色などの軽い設定不一致が
あるものとした。`ng` は、顔や身体の明確な破綻、人物の融合、文字化け、または
性別・年齢・職業・種族などが設定と明確に矛盾するものとした。

428枚を個別生成するとWeb版ChatGPTの画像生成上限を大きく消費する。一方、この
リストの肖像は高精細な鑑賞画像ではなく、キャラクターを識別できる正方形画像で
あればよいため、1枚に複数キャラクターを配置して切り出す方法が適している。

## Decision

`weak` と `ng` の両方を再生成対象とする。最初は1枚を5行5列に等分した
25キャラクターのグリッドで生成し、長時間の無応答とセル誤照合が見つかった後は、
安定して完了しやすく1セルの解像度も高い2行2列へ切り替える。

- 各セルは白背景、単独の全身またはポートレート、文字なしとする
- 名前、説明、役割、種族、旧画像の不合格理由をセルごとの指示に含める
- 年齢、性別、職業、種族、服装、毛色、持ち物を設定どおり明瞭に描かせる
- 生成後は境界を内側へトリムし、各セルを720x720 JPEGへ変換する
- グリッド全体をコンタクトシートで確認し、人物混在、枠ずれ、明確な破綻がない
  ものだけを採用する
- 既存のファイル名とURLを維持し、GitHub Releaseへ同名上書きする

全428枚を再生成し、グリッド単位の目視確認とセル単位の採否記録を経て採用した。

| リスト | weak | ng | 合計 | 配布先 |
|---|---:|---:|---:|---|
| 架空日常 | 191 | 67 | 258 | `fictional-daily-anime-character-v2` / `v2b` |
| 架空ファンタジー | 134 | 36 | 170 | `fictional-anime-character-v2` |
| 合計 | 325 | 103 | 428 | |

全428アセットを配布先Releaseへ同名上書きした。CSVのURLとファイル名は変わらないため、
CSV自体は変更しない。分割済み画像から未完了台帳を再計算し、残件0も確認した。

## Consequences

- 明確な設定矛盾を含む103枚と、品質の弱い325枚が改善される
- 5x5は生成枠の効率が高い一方、長時間の無応答、低いセル解像度、2x2履歴との
  誤照合が起きやすい。後半の2x2は生成回数が増える代わりに回収とQCが安定する
- 分割メタデータにセルごとの`accepted`を記録し、不採用セルだけを未完了台帳へ戻せる
- 画像URLを維持したため、利用側とCSVの変更は不要
