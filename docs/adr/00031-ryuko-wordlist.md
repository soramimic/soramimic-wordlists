# ADR 00031: ryuko(年代別の流行)ワードリストの新規作成

- Status: accepted
- Date: 2026-07-30
- Supersedes: none
- Superseded by: none
- Related: 00005(人名リストの読み方針) / 00023(gimukyoiku。「多い分にはいい」方針とLLMキュレーションの前例) / 00024(自動更新PRのAIレビューゲート)

## Context

「1960年代の流行」「1990年代の流行」のように**年代でフィルターして遊べる**単語リストが欲しい。替え歌の題材として「その時代を象徴する語」は歌詞との化学反応が大きく、年代フィルターがあれば「昭和縛り」「平成縛り」のような遊び方ができる。変わり種として平安(1000年代)・江戸のような前近代の流行も少数入れると面白い。

既存リストと違い、このリストには単一の機械可読なデータソースが存在しない。

- 機械的に取得できるのは Wikipedia「新語・流行語大賞」(1984年〜、CC BY-SA。単語自体は事実の羅列で著作物性が薄い)のみ
- 1984年以前は三省堂『明治・大正・昭和の新語・流行語辞典』等の書籍が主要資料で、電子データが無い
- 前近代(今様・判じ絵など)はまとまった一覧自体が存在しない

そのため sekitsui / insect のような「ソースへの追記同期」ではなく、gimukyoiku(ADR 00023)と同じ **LLMキュレーション+レビューで品質を担保する静的リスト**として作る。

## Decision

`ryuko.csv` を新設する。列は `id, original, surface, pronunciation, category, decade, era, year, description`。

### 収録基準

- 各年代に日本で広く「流行した」と言える語・モノ・遊び・ファッション・食べ物。**「その時代に存在した」だけでは不可**、ブーム・流行と言える裏付けがあるものだけ
- 出典の柱は (1) 新語・流行語大賞(1984〜、Wikipediaから機械抽出。大賞・トップテン・確認できた候補語) (2) 各年代の風俗史・流行史のLLMキュレーション(Wikipedia等で裏取りしたもののみ)
- 曲名・番組名・映画名そのものは原則入れない(現象・ジャンルとしての「ツイスト」「漫才ブーム」は可)。商品名は社会現象級(フラフープ・たまごっち等)なら可
- 同じ語が複数年代で流行した場合は**最も象徴的な1年代だけに置く**(1語1行)

### 除外基準(収録しないもの)

替え歌アプリの題材として不適切な語は、流行語大賞受賞語であっても収録しない。

- 災害・事故・事件・戦争・死に直接由来する語(震災語・戦時スローガン・事件名など)
- 差別的・侮蔑的な語、特定の実在個人への揶揄・スキャンダルが本質の語
- 性的・成人向けの語、薬物関連の語
- 政治スローガン・政局用語(中立的な世相語は可)

戦前の流行語には現代基準で差別的なものが多く、1940年代前半はほぼ戦時語のため、この年代の収録数が少ないのは意図的な結果である。

### 列の設計

- `category`: 流行の種類。`word`(流行語・言い回し)/`item`(モノ・商品)/`fashion`(服装・髪型・化粧)/`play`(遊び・娯楽・芸能)/`food`(飲食)/`other`。単一値
- `decade`: **流行のピークの10年区切り**。「1980年代」の形式。前近代は史料上ピークが幅でしか分からないことが多いので、代表的な10年を選ぶ(例: 元禄文化→1690年代、物語ブーム→1000年代)。利用側は `decade=1980年代` の完全一致で絞り込む
- `era`: 時代区分。平安/鎌倉/室町/安土桃山/江戸/明治/大正/昭和/平成/令和。decadeより粗い絞り込み軸(「昭和縛り」用)。年代区分の切り直し(例: 戦前/戦後)が欲しくなったらこの列を組み替えるか列を足す
- `year`: 代表的な流行年(西暦4桁)。流行語大賞由来は受賞年。特定できないものは NA
- `description`: 何がどう流行ったかの短い完結文(「。」終わり)。scientist / youtuber / gimukyoiku の description と同じ性格
- `surface` は `original` と同一(1語1行。表記ゆれ展開は必要になったら nations 方式で同一idに追記する)
- `pronunciation` は全行カタカナで付与(英字混じりの語が多く、surfaceからの推定に任せられないため)

### 生成と更新

- 初回生成は年代帯ごとのLLMリサーチ(裏取り付き)+流行語大賞のWikipedia機械抽出を、除外基準でフィルタしてマージした
- 自動更新の対象にはしない(歴史リストであり月次で増えるものではない)。年1回、流行語大賞の発表後に当年分を手動追記する程度を想定
- 増補は gimukyoiku と同じ「多い分にはいい」方針。ただし収録基準(流行の裏付け)と除外基準は増補時も必ず適用する

## Consequences

- 唯一の網羅的ソースが無いリストなので、**収録の完全性は保証されない**(特に戦前・前近代はキュレーションの主観が入る)。「この年代にこれが無いのはおかしい」という指摘は歓迎で、基準を満たせば追記すればよい
- 「流行した年代」の判定には幅がある(例: けん玉は複数回ブームがある)。decade は代表値であり、厳密な初出年ではない
- 流行語大賞由来の語は自由国民社の賞の存在を前提にするが、収録するのは語そのもの(事実)であり、公式サイトの解説文は転載しない
- 画像列は初回は持たない。欲しくなったら gimukyoiku(ADR 00027/00028)と同じ方式で後付けできる
