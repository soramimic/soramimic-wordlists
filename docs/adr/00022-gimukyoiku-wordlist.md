# ADR 00022: gimukyoiku(義務教育)ワードリストの新規作成

- Status: accepted
- Date: 2026-07-28
- Supersedes: none
- Superseded by: none
- Related: 00006(fictional_scientist。自動更新バッチ対象外の取り込み型リストの前例) / 00009(scientist。facet列とdescription列の書式の前例)

## Context

「授業で習ったあの単語」は替え歌・空耳の素材として通用度が高い(聞き手のほぼ全員が知っている)のに、既存リストは生物・人名・地名などドメイン特化で、学校の学習用語を横断するリストが無かった。

義務教育(小中学校)の教科書・授業に登場する語は、Wikidata のような単一の構造化データ源から機械的に引けない(「教科書に載っている」ことを表すプロパティが無い)。そのため sekitsui / insect のような自動更新型は成立せず、AI生成による手動キュレーション型になる。

## Decision

`gimukyoiku.csv` を AI 生成による手動キュレーションで新設する。自動更新バッチ(`tools/update_*.py` / 月次ワークフロー)の対象外とし、語の追加・修正は通常の PR で行う(fictional_scientist と同じ運用)。

### 列構成

`id, original, surface, pronunciation, subject, description`

- `id`: 連番。同一概念の別表記(側方倒立回転と側転、つづりとスペルなど)は nations と同じく同じ id で併記する(初回時点で9組)
- `original` / `surface`: 同一の値。学習用語はそれ自体が表示形かつ変換対象
- `pronunciation`: カタカナ読み
- `subject`: 教科。facet フィルタ軸
- `description`: 20〜60字程度の短い説明。「義務教育の授業でどう登場する語か」がわかる文にし、「。」で終える(scientist の書式に準拠)

### subject(教科)区分は中学9教科ベース

`国語 / 社会 / 数学 / 理科 / 英語 / 音楽 / 美術 / 保健体育 / 技術・家庭` の9区分。

- 小学校のみの教科は対応する中学教科に吸収する(算数→数学、図画工作→美術、体育→保健体育、家庭→技術・家庭)。「算数」と「数学」を別区分にすると利用側の絞り込み軸として細かすぎ、同じ概念(分数・円周率など)がどちらに属すか恣意的になるため
- 複数教科にまたがる語(例: レオナルド・ダ・ヴィンチ=社会/美術)は sekitsui 以降の慣習どおり `/` 区切りの多値にし、`subject~=美術` の部分一致で絞り込む
- 社会の歴史/地理/公民、理科の物理/化学/生物/地学のような教科内の分野は区分にしない。粒度を揃えると区分が15超になり、利用側の軸として細かすぎる

### 収録基準

- 小中の教科書・授業に実際に登場する語。学習用語(光合成・連立方程式)に加え、授業で扱う人名・作品名・事件名(夏目漱石・枕草子・大化の改新)も含める。「習った!」という共通体験が空耳の面白さに直結するため用語に限定しない
- **学校生活の一般語・授業運営語は収録しない**(2026-07-30 追記)。プリント・ワークブック・暗記・ペアワークのような「どの教科でも成立する学校の風景の語」は、教科facetの意味を薄めるため対象外とする。教科固有の指導技法・活動(音読・シャドーイング・調理実習・準備運動など)は教科の中身なので収録してよい。初回リストに混入していた26語(主に英語枠)は全教科の精査で削除した
- 各教科100語以上を目安に、定番・有名どころを厚めに収録する
- 特定の教科書会社にしか載らない語や、高校以降の内容は入れない

## Consequences

- 自動更新が無いため、学習指導要領の改訂で語が古びても自動では追随しない。追加・修正は PR ベースで行う
- AI 生成のため個々の語の「教科書掲載」の厳密な出典は無い。明らかな誤り(義務教育で扱わない語・読みの誤り)は見つけ次第 PR で修正する
- 人名は scientist(野口英世など)と重複しうるが、insect と sekitsui のカマキリと同様、リストごとに閉じた正しさとして許容する
- app 側 setting.json での facet 定義(`subject~=`)は soramimic 側で対応する(本リポジトリの範囲外)
- 初回時点では image 列を持たない。将来付けたくなったら列追加で対応する
