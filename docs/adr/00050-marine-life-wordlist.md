# ADR 00050: 海の生き物ワードリスト

- Status: accepted
- Date: 2026-08-11
- Updated: 2026-08-12（収集上限撤廃・実写・説明根拠・生成fallback拡充）
- Supersedes: none
- Superseded by: none

## Context

既存の `sekitsui.csv` は脊椎動物を広く収録するが、海の生き物だけを選ぶ軸はなく、
ヒトデ・ナマコ・フジツボなどの海棲無脊椎動物も対象外である。海洋性は単一の分類群
ではなく、分類木だけから安全に判定できない。そこで分類木全体から推測するのではなく、
日本語名と学名が対応する資料を起点に、海洋性を種ごとに検証する必要がある。

## Decision

- `marine_life.csv` を追加し、海水域を通常の生活場所に含み、日本語名を確認できる現生の
  動物名を収録する。海鳥、陸生・淡水専生の動物、化石・絶滅動物は対象外とする。
  回遊種は海で生活する時期が明確なものを含める。
- [WoRMS](https://www.marinespecies.org/)、
  [JODC海洋生物分類コード](https://www.jodc.go.jp/jodcweb/JDOSS/infoTaxonomicCode_j.html)、
  Wikidataと一般的な分類資料を照合した `tools/marine_life_source.csv` を正本にする。
  分類階層は更新され続けるWoRMSを優先し、JODCは日本語名の参考資料として使う。
  2026-08-12の拡張では、JODCの和名と学名を候補にし、WoRMSの有効なAphiaID側で
  `isMarine=1` と種階級を再確認した。まず821件、その後に件数上限を撤廃して2399件、
  さらに原表の全分類を再走査して855件、合計4075件を既存179件の末尾へ追加した。
  WoRMSの近似一致は採用せず、旧学名側だけの海洋フラグも採用しない。
- 初版179件の説明はレビュー済みの独自文を維持する。2026-08-12に追加した4075件は、
  当初の科名・生物名だけの定型文を廃止する。Wikidata QIDから日本語Wikipedia記事へ
  直接たどり、表示名と記事名が一致したときだけ、冒頭部の形態・生態・生息域を表す
  完結文をカード向けに短く整える。名前検索、別名記事の流用、分類だけの文は採用しない。
  採用した317件は記事URL、版ID、取得日、元文、生成文を根拠台帳へ固定する。
  Wikipediaで有用文を確認できない場合は、WoRMS REST APIで再確認したstatus・rank・
  `isMarine=1` と、種自身に紐づく最大体長・IUCN評価だけから決定的に生成する。
  4064件はaccepted Species、2件はaccepted Subspeciesである。残る9件はJODCで使われる
  海洋生物名だが、WoRMSで疑問名・要検討分類群等とされるため、その位置づけを説明に明記する。
  Traitsがない種は、学名・科・出典名で欄を埋めず空欄にする。WoRMSのDB説明文は転載しない。
  使用した百科事典の版と元文、最小限の構造化事実、参照文献、品質状態、取得日、API URLを
  `tools/marine_life_description_sources.jsonl` に固定し、説明と一対一でCI検証する。
  最大体長など同じ構造化事実から同じ短文になることは許容するが、名前を主語に繰り返す文、
  学名・出典名だけの文、根拠台帳から再生成できない文はvalidatorで拒否する。
- 候補抽出と外部照合の結果はレビュー可能な台帳へ固定し、配布時にネットワークへ依存しない。
  `tools/update_marine_life.py` が台帳から配布CSVを決定的に再生成し、CIで `--check` を実行する。
- 台帳の `id` は0始まりの固定連番とし、新規項目は末尾へだけ追加する。通常の再生成は
  既存項目の削除を拒否し、意図した訂正時だけ `--allow-removals` を使う。
- `class` は `哺乳類` / `爬虫類` / `魚類` / `無脊椎動物` の4値とする。
  `vertebrate` は前3分類を `脊椎動物`、最後を `無脊椎動物` として束ねる。
  これにより細分類と上位分類の両方をVideoの既存facet機構で選択できる。
- `order` / `family` は表示と追加の絞り込みに使える原則日本語の分類名、`description` は空欄または
  8〜90字で単独で完結する説明とする。確認できた項目だけ `wikidata` QIDを保持する。初版のQIDは
  `sekitsui.csv` で和名と `class` がともに一致し、非空QID候補が一意な分類群に限って
  引き継ぐ。同名でも分類が異なるシマアジ（魚と鳥）のような項目は名前だけで結合しない。
  JODCに日本語の目・科がない場合は、WoRMSの有効レコードの学名に `目` / `科` を付けて
  欠損を避ける。
- `sekitsui.csv` との重複は許容する。片方は分類群リスト、片方は海洋テーマの選集であり、
  利用目的が異なるためである。`marine_life.csv` 内の同名重複と表記揺れは認めない。
  既存リストと分類体系の版が異なる場合は、本台帳側では上記の優先順を採る。
- 初版の4分類共通SVGに加え、Wikidataの分類群QID・学名とWoRMSの有効学名が一致する
  Wikimedia CommonsのP18を実写候補にする。Commons APIで作者、ライセンス、寸法、SHA-1を
  固定し、PD / CC0 / CC BY / CC BY-SA、320x200以上の写真らしいラスター画像だけを採用する。
  QIDはP225の完全一致に加えてP171の祖先がAnimaliaへ到達することを検査し、同名の植物などを除外する。
  配信用URLは元画像への集中アクセスを避けるため、Commonsが生成した幅960px以下のサムネイルを使う。
  図版、標本、化石、分布図などは機械的に除外する。採用根拠は
  `tools/marine_life_image_sources.jsonl` に保存し、台帳との一対一対応をCIで検査する。
- 実写が採用できない行は、同じ科で5件以上あれば科別、残りの同じ目で5件以上あれば目別の
  写真風生成合成画像を生成候補にする。初回は候補188分類のうちCDP生成上限までに取得・検品した
  112科を採用し、2870件中1564件（54.5%）を科の粒度で表す。未生成の1306件は、
  哺乳類、爬虫類、魚類、刺胞動物、甲殻類、軟体動物、
  棘皮動物、蠕虫型、その他無脊椎動物の9形態群画像を使う。閾値は実写未取得行だけで数え、
  科を目より優先する。したがって実写追加後も、残存する対象件数から計画を再検証できる。
  個別種を断定せず、台帳内の最大3和名・3学名を視覚参考にした代表的な体型を示す。960x600 WebPへ
  決定的に整形し、すべてに「生成イメージ」と焼き込んで特定種の実写とは扱わない。
  生成日、生成手段、用途、プロンプト、元画像と配布画像のSHA-256は
  `tools/marine_life_generated_images.json` に固定し、配布画像との一致をCIで検査する。
- Soramimic Videoでは既存 `animal_card` を既定レイアウトにする。同レイアウトが参照する
  `image` / `original` / `order` / `family` / `description` を本CSVが提供する。

## Consequences

- 哺乳類・爬虫類・魚類・無脊椎動物、または脊椎動物全体で自然に絞り込める。
- キュレーション方式なので海洋生物全体を網羅せず、分類改訂にも自動追従しない。
  追加・訂正時には台帳と根拠をレビューする必要がある。
- 4254件中1384件はCommons実写、1564件は科別、1306件は形態群別の写真風生成イメージで、画像列の
  充足率は100%である。生成イメージは、再利用条件と同定を確認できた実写が見つかった
  時だけ置き換える。画像生成のもっともらしさを種同定の根拠には使用しない。
- DB生成説明は取得済みの根拠以上の形態・行動・生息域を推測しない。そのため4254件中1139件は
  説明が空欄になるが、科名だけを言い換えた説明より検証可能性を優先する。日本語Wikipedia由来の
  加工文にはCC BY-SA 4.0条件が適用され、根拠台帳のページURL、版ID、変更有無で帰属を追跡する。
- 既定レイアウトとfacetの公開には、利用側リポジトリの対応表・設定およびsubmodule更新が必要。
