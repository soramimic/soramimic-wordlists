# ADR 00047: football をJリーグ経験者のWikipediaベースへ再構築する

- Status: accepted
- Date: 2026-08-09
- Supersedes: ADR 00005 / 00016 のうち football の母集団と出典
- Extended by: ADR 00048 (任意追加する収録範囲とフィルター)

## Context

`football.csv` はヨロスー様提供の歴代名鑑を母体に、Wikipedia のJ1〜J3現役
ロースターを追記してきた。その結果、Jリーグ経験者、海外だけで活動した選手、
監督、マスコットが混在し、「全世界」でも「Jリーグ」でもない収録範囲になっている。

既存7,344人のうち6,324人は提供データ由来、1,020人はWikipediaロースター由来で
ある。提供データ由来の登録名だけの行や記事のない人物は、Wikipedia/Wikidataから
同値に復元できない。一方、動画カードに必要な説明・画像・ポジションはWikipedia
記事がある人物ほど品質を保ちやすい。

## Decision

- `football` の対象を、選手としてJリーグクラブに在籍した経験をWikipediaで確認
  できる人物に限定する。監督歴だけの人物とマスコットは含めない
- 人物の母集団は日本語版Wikipediaの現役ロースターテンプレート、Jリーグ現加盟・
  旧加盟クラブの選手カテゴリ、人物記事から作る
- 「選手としてJリーグに登録された経験」の確認には、Jリーグ公式データサイトの
  「全選手一覧」をローカル照合索引として使う。Wikipedia候補の登録名が一意に一致
  した場合だけ `verified` とし、同名人物や不一致は本人確認が済むまで `unverified`
  とする
- 氏名、姓名の表層、説明、画像、ポジションはWikipedia/Wikidataから生成する
- 読みは人物記事冒頭を第一ソースにする。記事だけで確定できない場合に限り、
  Jリーグ公式の個別選手情報にある氏名・英字表記を照合材料として使う
- Jリーグ公式の一覧は取得時のローカルcacheとしてだけ扱い、リポジトリや成果物へ
  再配布しない。公式の説明文、写真、選択・配列もCSVへ複製しない。成果物には照合
  できた人物の `player_id`、個別ページURL、照合方法だけを根拠として記録する
- 公式情報で読みを個別に検証・補完する場合も、取得URLと取得日をmanifestへ記録する
- 読みを確定できない人物は推測で追加せず、`unverified` として候補manifestへ残す
- 人物ごとにQID、根拠となるWikipedia記事・クラブカテゴリ、取得時点をmanifestへ
  記録する。CSVの連番`id`だけを本人識別子にしない
- 初回は既存 `football.csv` を上書きせず候補CSVを生成する。件数、重複、読み、
  Jリーグ在籍根拠をレビューした後に置き換える

## Consequences

- ヨロスー様提供データへの依存とクレジットは、候補版への切替時に外せる
- 記事のない選手や登録名だけの人物は失われるため、現在の7,344人より少なくなる
- 全行が記事と在籍根拠を持つため、曖昧さ回避ページ由来の壊れたdescriptionや、
  Jリーグ未経験の海外選手が混ざる問題を減らせる
- クラブカテゴリは、そのクラブがJリーグへ参入する前後の所属選手を含む場合がある。
  カテゴリ一致だけの候補は厳密な「Jリーグ在籍」と断定せず、公式登録歴を照合
  できない間はmanifestで `unverified` とする
- Wikipedia本文・画像は各ライセンス条件に従い、Wikidataの構造化データはCC0として
  扱う。Jリーグ公式の文章・写真・一覧データは再配布しない
