# ADR 00036: 非教科の subject「学校生活」をやめる

- Status: accepted
- Date: 2026-08-02
- Supersedes: 00035
- Superseded by: none
- Related: 00022(gimukyoiku の収録基準) / 00035(学校生活の区分を置いた判断)

## Context

ADR 00035 で、教科に紐づかない行事の語を教科 facet を薄めずに残すために、非教科の
subject `学校生活` を1つ足した。実際に入ったのは**運動会と応援合戦の2語だけ**だった。
徒競走・玉入れ・綱引き・組体操などは体育の授業で扱う運動なので保健体育に残ったため。

この2語のために、次のコストが恒常的に乗ることが分かった。

- subject の値が9区分から10個に増え、「教科」という軸の意味が濁る
- 「既定では含めない」を実現するために、利用側(soramimic)の setting.json で教科9つに
  `default: true` を付ける必要があった。`compileWhere` は未チェックの facet を
  「制約なし=全行」として扱うためで、この回避策には**利用者が教科のチェックを全部
  外すと学校生活が混ざる**という穴が残る
- 区分が増えたぶん、新しい語を足すたびに「教科の活動か、行事か」の線引きの判断が要る

2語の価値に対して、リポジトリ側の区分と利用側の設定の両方に仕掛けが要るのは
釣り合わない。

## Decision

**subject `学校生活` をやめ、運動会と応援合戦の2行を削除する。** subject は
ADR 00022 の9区分に戻す。

これは ADR 00022 の「学校生活の一般語は収録しない」に戻る判断でもある。
教科に紐づく活動(徒競走・玉入れ・綱引き・騎馬戦・大玉転がし・二人三脚・
台風の目・組体操)は体育の運動として `保健体育` のまま残す。

## Consequences

- 3667行 -> 3665行。subject は9区分に戻る
- 利用側の setting.json から `学校生活` の値と、そのために付けた教科9つの
  `default: true` を外す(soramimic 側で別途対応)
- 行事そのものの語(運動会・応援合戦・入学式・卒業式など)は今後も収録しない。
  再び欲しくなったら、subject を増やすのではなく別リストとして持つほうが素直
