# ADR 00053: 公開人物ページによる名字読みの根拠

- Status: accepted
- Date: 2026-08-14
- Related: 00038 / 00050 / 00051 / 00052

## Decision

公開人物ページで名字の表記と読みを同一人物について確認できた組は、
`evidence_sources=web_person` として区別する。姓辞典、検索結果の要約、
人物を同定できない記載だけでは確認済みにしない。

公開する根拠台帳は、名字、読み、確認状態、根拠URL、出典種別、確認日など、
判定の確認に必要な最小項目だけを保持する。取得元ページ本文、連絡先、
検索記録や不採用候補は再配布しない。
