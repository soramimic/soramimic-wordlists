# ADR 00003: nations.csv の表記固定・ISO マップ・status 列

- Status: accepted
- Date: 2026-07-05
- Supersedes: none
- Superseded by: none

## Context

nations.csv の 193 行は国連加盟国と 1 対 1 対応しているが、表記は「アメリカ」「イギリス」「グルジア」のような独自の通称で、ソース(mledoze/countries の日本語名)とは一致しない。名前だけでは機械的に突き合わせられず(「コンゴ」が 2 行、「ギニア」に赤道ギニアが含まれる等)、自動更新でソースの表記に置き換えると既存の使い勝手と id が壊れる。また、国の改名(グルジア→ジョージア)や国連脱退・消滅が起きたときに、古い名前を消すのではなく「現存するか」を区別して残したい。複数の読み(アメリカ/アメリカ合衆国/米国)も将来持てるようにしたい。

## Decision

- **既存行の original / surface / id は自動更新で一切書き換えない。** ソースとの対応は `tools/nations_map.csv`(ISO 3166-1 alpha-3 cca3 → id)で管理する。マップは初回に全 193 国分を人手確認して固定した(コンゴ 2 行は COG=110/COD=118、id 179 のギニアは GNQ=赤道ギニア)
- `status` 列を追加する。値は `current`(現存・国連加盟)/ `former`(旧称・脱退・消滅)
- 自動更新(`tools/update_nations.py`)がやるのは次の 3 つだけ
  - 新規加盟国を末尾に追記(id は連番、表記はソースの日本語通称、status=current)
  - 加盟国でなくなった国の行を status=former に変更(行は消さない)
  - 再加盟したら status=current に戻す
- **別名・旧称・複数読みは同じ id の行を手動で追加する**(例: id=29 に「ジョージア」current と「グルジア」former、id=190 に「アメリカ」と「アメリカ合衆国」を両方 current で)。自動更新が status を管理するのはマップの original と一致する行だけなので、同 id の手動行は保護される。国の改名時はマップの original を新表記に更新すること(そうしないと旧表記の行が加盟国として current に戻される)
- Wikidata の ja エイリアスによる別名の自動取得は見送る。「米国」「USA」のような読み上げに向かない表記が多く、フィルタの整備コストがノイズ除去の価値を上回らないため。必要になれば候補生成+人手確認の半自動として別 ADR で設計する
- ソース異常への防御として、加盟国数が 180〜210 を外れた場合と増減が 5 か国を超えた場合はエラーで中断する

### 別表記行の追加方針(2026-07 追記)

空耳変換では同じ国に対する表記・読みの候補が多いほど価値があるので、次の 5 種類を同じ id の行として手動で足す。追加行は `status=current`、image / image_page / wikidata は同じグループの現行行からコピーする(グループ内で国が同じである以上、旗も QID も同じもので正しい)。

| 種別 | 例 |
|---|---|
| 正式名称 | 韓国 → 大韓民国、アメリカ → アメリカ合衆国、コンゴ → コンゴ共和国 / コンゴ民主共和国 |
| 通称 | 朝鮮民主主義人民共和国 → 北朝鮮、中央アフリカ共和国 → 中央アフリカ |
| 漢字略称 | アメリカ → 米国、イギリス → 英国、オーストラリア → 豪州 |
| 別読み | 日本(ニホン)→ 日本(ニッポン) |
| 別カナ表記・新旧呼称 | オランダ → ネーデルラント、トルコ → テュルキエ、チェコ → チェキア |

採否の基準:

- 正式名称は「日本語の報道・外交文脈で実際に目にするもの」に限る。具体的には G20・安保理常任理事国・日本と関係の深いアジア諸国、王国 / 公国 / 大公国 / 連邦のように通称と語形がはっきり違うもの、同名を区別できるもの(コンゴ 2 行、ドミニカとドミニカ共和国)。小国に定型の「〜共和国」を機械的に付けるだけの表記は、変換候補としての価値が薄くノイズになるので足さない
- 表層が長すぎるもの(目安 25 文字超。「グレートブリテン及び北アイルランド連合王国」等)は足さない。空耳の変換単位として使えないため
- 漢字略称は現代日本語で通用するもの(米国・英国・豪州)だけ。「仏蘭西」「独逸」のような古風な当て字は足さない
- 迷ったら足さない。ADR 00014 のとおり既存行を劣化させないことが優先で、候補の網羅は目的ではない

`pronunciation` 列(surface の直後)を追加した。漢字を含む表記は surface からの読み推定が当てにならないため、追加行には必ずカタカナ読みを入れる。既存行も読みが自明でないもの(中国・朝鮮民主主義人民共和国 等)は補完する。カタカナだけの行は空のままでよい(利用側が surface から推定する)。

**`tools/nations_map.csv` は別表記を足しても変更しない。** マップは ISO コード(cca3)→ (id, original) の 1 対 1 対応表で、自動更新の status 同期はこのマップの `original` と一致する行だけを対象にする(`update_nations.py` の `member_keys` / `former_keys`)。別表記行の `original` はマップに載っていないので同期から外れ、手で決めた status がそのまま保持される。逆に別表記をマップに足すと 1 つの ISO コードに複数行が対応することになり、マップの一意性が壊れる。国が改名したときにマップの `original` を新表記へ更新する運用も、この 1 対 1 を前提にしている。

## Consequences

- 国連加盟国の増減は年次バッチで自動反映され、既存の表記・id・手動で足した別名行は壊れない
- 利用側は `status=current` で絞れば現存国のみになる(status を見ない場合は旧称も候補に含まれる)
- 新規加盟国の表記はソースの日本語通称がそのまま入るため、既存の通称スタイルと合わない場合は PR レビューで手直しする(マップの original も合わせて直すこと)
- 国の改名はソースからは機械判定できないため、従来どおり人が気づいて手動対応する(新表記の行を追加し、旧表記を former にする)
- 1 グループが複数行になるので、利用側で「国名を1つだけ出したい」用途では id ごとに 1 行選ぶ必要がある(空耳変換は候補が多いほどよいので、この方向の不便は受け入れる)
- 別表記は人手で足すため網羅的ではない。未収録の表記は気づいた人が上記の基準に沿って追加する
